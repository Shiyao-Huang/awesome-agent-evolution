Self Evolve 位于五类循环的交叉点：规格到执行循环、搜索循环、评估器循环、反思循环和种群循环。

核心品牌论点是：**Self Evolve 不是单一论文类别，而是统一“生成、评估、记忆、改进”系统的产品与研究层。**

## 五条支流

| 领域 | 被进化对象 | 评估器 | Self Evolve 角度 |
|---|---|---|---|
| AutoML + LLM | ML 流水线 / 程序 | 数据集指标、部署检查 | 自然语言到优化实验 |
| NAS + LLM | 架构 / 代码 | NAS 基准、准确率 / 成本 | 架构基因组与质量-多样性 |
| LLM 自我改进 | 输出、轨迹、模型权重 | 人类 / 自动 / 任务反馈 | 经验飞轮 |
| 进化计算 + LLM | 程序、提示词、启发式 | 目标函数 | 通用进化引擎 |
| Agent 框架 | Agent 角色、工作流、工具 | 任务完成度、评估套件 | 进化式 Agent 组织 |
