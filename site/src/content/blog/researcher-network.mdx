AI 自我进化是一个跨学科、跨机构的新兴领域。以下是推动这一领域的核心研究力量。

## 核心研究组

### UBC Evolutionary AI Lab (Jeff Clune)

Jeff Clune 教授团队是目前 Agent 自进化方向的高可见度团队之一：

- **Jeff Clune**：开放式进化、Quality Diversity、POET 先驱。前 Uber AI Labs。
- **Shengran Hu**：ADAS 第一作者，同时参与 DGM。UBC / Vector Institute 博士生。
- **Cong Lu**：进化 AI 研究者，ADAS/DGM 共同作者。
- **Jie (Jenny) Zhang**：DGM 第一作者。

产出：ADAS (ICLR 2025)、DGM (2025)、OMNI-EPIC、POET 系列

### Google DeepMind

- **Alexander Novikov** 等：AlphaEvolve，进化式算法发现
- **Pushmeet Kohli**：AI for Science 负责人
- 基于 FunSearch (Nature 2023) 扩展到完整代码库进化

### AIWaves + 浙江大学

- **Wangchunshu Zhou**：Agent Symbolic Learning 第一作者，AIWaves 创始人
- **Ningyu Zhang**：浙江大学，知识图谱与 Agent 系统
- **Huajun Chen**：浙江大学教授

产出：Agent Symbolic Learning (NeurIPS 2024)

### Northeastern University + MIT

- **Noah Shinn**：Reflexion 第一作者
- **Shunyu Yao**：ReAct、Reflexion 共同作者（MIT）

产出：Reflexion (NeurIPS 2023)

## 合作模式

核心合作网络呈现以下特征：

1. **师徒链**：Clune → Hu/Lu/Zhang，形成持续深耕的团队
2. **产学研结合**：AIWaves(Agent Symbolic Learning)、Google DeepMind(AlphaEvolve)
3. **跨组交叉**：Reflexion 的 Shunyu Yao 同时参与 ReAct ( Princeton)

## 值得关注的新兴方向

- **安全自进化**：浙大 ZJU-LLM-Safety 的 DARWIN 项目探索攻击策略的自动进化
- **自评判训练**：OPPO Mente Lab 的 LLM-Self-Judge
- **社区驱动**：OpenEvolve 作为 AlphaEvolve 的开源复现

Self Evolve 将持续更新这个研究者图谱，追踪领域的动态发展。
