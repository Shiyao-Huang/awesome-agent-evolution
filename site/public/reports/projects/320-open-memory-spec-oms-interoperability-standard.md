## 1. Role in Self Evolve

OMS defines a portable and auditable memory standard for autonomous agents, including a binary memory grain format and context assembly language. It matters because self-evolving agents need repeatable harness control, measurable feedback loops, and reusable skill procedures before claiming stable improvement.

## 2. Working Principle

define immutable memory grain containers -> standardize query and context-assembly languages -> enforce portable and auditable memory exchange across runtimes -> reduce lock-in and memory migration friction for long-lived agents
