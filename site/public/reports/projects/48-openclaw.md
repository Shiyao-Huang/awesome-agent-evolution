# OpenClaw Model Card

## One Sentence

OpenClaw is the product-runtime sample for asking whether self-evolving agents are actually usable by people.

## Three Sentences

The raw capture describes a local-first assistant across many channels, with live canvas, tools, cron/session concepts, and skill support. It is not primarily a paper-code project; it is a user-facing agent operating system surface. That is exactly why it belongs in the main site: product usability is one of the user's explicit evaluation questions.

## Teaching Use

Use OpenClaw to teach the gap between "agent method" and "agent product." A usable agent needs channels, permissions, memory, tool access, sessions, scheduling, and recovery paths. OpenClaw also provides the context for PinchBench, which evaluates real-world OpenClaw tasks.

## Evidence And Limits

The raw capture reports 374k stars, 77.7k forks, and a broad multi-channel product surface. These numbers are raw snapshot values and should be rechecked with authenticated GitHub metadata. The deeper analysis should inspect whether skills and sessions create real learning loops or mainly operational convenience.
