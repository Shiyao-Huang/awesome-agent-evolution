## 1. Role in Self Evolve

SkillClaw 直接回应“skill 如何自进化”：它从真实 agent 会话中抽取、去重、验证并共享可复用 skills，让单用户和多 agent 团队都能把经验沉淀为演化资产。

## 2. Working Principle

agent session data -> proxy capture -> skill dedup/improvement/verification -> shared evolve server -> reused skills
