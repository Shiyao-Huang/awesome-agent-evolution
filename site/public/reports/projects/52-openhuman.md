# OpenHuman Model Card

## One Sentence

OpenHuman is a UI-first personal-agent product with local memory, integrations, typed tools, and token compression.

## Three Sentences

It overlaps directly with the user's product-usability concern: the agent must be useful in daily life, not only impressive in a benchmark. The raw capture describes an Obsidian-compatible wiki, local-first memory, 118+ integrations, automatic fetch, typed tools, web search/fetch, voice, messaging, and token compression. In the graph it belongs beside OpenClaw and Hermes as a personal agent runtime.

## Teaching Use

Use OpenHuman to teach the product side of self-evolution: memory ownership, UI, integrations, recurring fetch, and token compression. It is a useful counterweight to paper-code systems because it asks whether the agent can survive real user workflows.

## Evidence And Limits

The raw capture reports 25.1k stars, 2.3k forks, Rust/TypeScript implementation, GPL-3.0 license, and release `v0.54.0`. The next analysis should verify which parts are self-improving versus conventional personal-assistant features.
