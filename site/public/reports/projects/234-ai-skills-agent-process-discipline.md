## 1. Role in Self Evolve

ai-skills is a small behavioral skill library for coding agents. It matters to self-evolution because it treats planning, debugging, verification and multi-agent coordination as reusable process assets rather than one-off prompt instructions.

## 2. Working Principle

agent task -> triggered behavioral skill -> process discipline for planning, testing, review, debugging or verification -> safer reusable execution habit
