## 项目简介

Awesome AI Agents 2026 是一份精心策展的 AI Agent 生态资源清单，覆盖 2026 年这个"Agent 走向主流、AI 成为基础设施"之年的完整技术版图。项目收录了 420+ 项资源，横跨 25 个分类，系统性地追踪了从基础模型、Agent 框架、编码 Agent 到具身智能、移动 Agent 等前沿领域的最新进展。

该项目不仅仅是一个简单的链接列表，而是一个结构化的 AI 生态导航系统。它提供了 56 个场景到工具的映射（Scenario Guide）、8 个精心策划的工具组合方案（Stack Recipes）、15 个反面教材（Anti-Picks）以及并排对比表格（Compare Tables）。每个条目都带有状态标签（如"新增"、"热门"、"已归档"、"待验证"等），帮助读者快速判断项目的成熟度和可靠性。

项目的更新频率极高（最后更新于 2026 年 5 月 20 日），追踪了所有主要 AI 厂商的最新动态。从 OpenAI 的 GPT-5.5 到 Anthropic 的 Claude Opus 4.7，从 Google 的 Gemini 3.5 到 Meta 的 Muse Spark，以及各类 Agent 框架、工具协议和安全方案，均以时间线形式记录，形成了 2026 年 AI Agent 发展的完整编年史。

## 核心模块分析

### 1. 基础模型追踪 (Foundation Models)

系统追踪了 20+ 提供商的 60+ 模型。按公司分类（OpenAI、Anthropic、Google DeepMind、Meta、DeepSeek、Zhipu AI、Xiaomi 等），记录每个模型的发布日期、关键能力和 API 定价。时间线覆盖 GPT-5.5 系列到 Claude Opus 4.7，Gemini 3.1/3.5 到 Llama 4 系列，以及中国厂商的 GLM 5、Qwen3.5 等模型。还提供了 API 成本和上下文长度的对比表格。

### 2. Agent 框架生态 (Agent Frameworks)

收录 23+ Agent 框架，涵盖 smolagents、LangGraph、CrewAI、AutoGen 等主流项目。每个框架标注了技术特点、适用场景和成熟度状态。配合 Agent IDEs & Visual Builders（8+）、Agent Memory（10+）、Tool & API Integration（15+）等分类，形成了 Agent 开发工具链的完整地图。

### 3. 协议与标准 (Protocols)

追踪 MCP（Model Context Protocol）和 A2A（Agent-to-Agent）等 Agent 互操作性标准的进展。记录了各厂商对 MCP 的采用情况以及跨框架 Agent 通信协议的演进。

### 4. 场景导航系统 (Scenario Guide + Stack Recipes)

56 个场景到工具的映射（如"构建客服聊天机器人该用什么"、"做代码审查 Agent 选什么框架"），以及 8 个经过验证的工具组合方案。这是该项目的独特价值——不仅仅是列举工具，而是提供"在什么场景下用什么组合"的实操指导。Anti-Picks 部分列出了 15 个"不该用什么"的反面案例，帮助开发者避开常见陷阱。

### 5. 安全与评估 (Security + Evaluation)

Agent Security 分类收录了 14+ 安全工具和方案（提示注入防御、护栏系统等）。Evaluation & Observability 分类涵盖 17+ 测试、监控和基准工具。Benchmarks & Leaderboards 分类追踪了 11+ 评测排行榜的动态。
