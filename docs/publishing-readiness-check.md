## Current Target

The site should not be only an Awesome list. It should behave like a public knowledge product:

- Raw material proves coverage.
- Paper processing turns raw papers into research arguments.
- Blog/SEO pages make the knowledge discoverable.
- Project model cards turn repositories into learnable engineering patterns.
