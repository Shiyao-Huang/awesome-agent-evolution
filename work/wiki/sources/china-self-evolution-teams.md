## Key Findings

1. **学术界驱动模式**: China = academia-led + industry-following (vs SV = industry-led)
2. **4大高校集群**: SJTU (安全领先), Tsinghua (应用驱动), ZJU (策略优化), PKU (框架创新)
3. **2大产业力量**: Alibaba AgentEvolver (开源框架), Shanghai AI Lab Intern·Agent (科学发现)
4. **政府协调**: CAICT 2025年3月联合20+企业发布 Agent 标准术语框架
5. **独特方向**: 自进化安全 (SJTU), Agent 医院 (清华AIR), 小模型自进化 (阿里 7B/14B)
