## Key Findings (6 Mechanism Insights)

1. **Evaluation bottleneck is universal** — every self-evolution system hits verification ceiling
2. **Self-evolution is non-monotonic** — 4 erosion channels identified (catastrophic forgetting, reward hacking, distribution shift, mode collapse)
3. **Code is the universal mutable representation** — prompt < memory < weight < code depth spectrum confirmed by reviewers
4. **Multi-agent gains from knowledge building, not parallelism** — debate/collaboration value is in cross-pollination
5. **Verification must be immutable** — mutable verifiers lead to self-delusion loops
6. **Field converging on protocol-level abstractions** — ADAS, DGM, Agent Symbolic Learning share architectural patterns
