## 概述

ProgPrompt 是一种通过程序化提示（Programmatic Prompting）来引导 LLM 为机器人生成可执行任务计划的方法。它将环境状态、可用技能和任务目标以结构化的 Python 程序形式呈现给 LLM，使 LLM 能够生成包含条件判断、循环和错误处理的复杂任务程序，支持机器人在动态环境中的鲁棒执行。

## 核心特性

- **程序化提示**：以 Python 代码形式而非纯文本来表示任务上下文和目标
- **环境状态编码**：将物体位置、状态等环境信息编码为程序变量
- **错误处理**：生成的程序包含异常处理和重试逻辑
- **可组合技能**：支持将基础技能组合为复杂任务序列

## 技术栈

- Python
- 大型语言模型 (GPT-4 / Codex)
- 场景理解与物体检测
- 机器人技能 API

## 与 Self Evolve 的关联

ProgPrompt 是反馈-精炼和智能体编排的结合：
- **反馈-精炼**：执行过程中的错误反馈驱动 LLM 修正程序逻辑
- **智能体编排**：通过程序化方式编排多个机器人技能的执行流程

## 分类

具身智能体方向中的结构化任务规划，属于「程序化提示驱动的机器人控制」。
