## 概述

DeepChem 是一个面向科学领域的开源深度学习平台，专注于药物发现、材料科学、生物学和量子化学等应用场景。它提供了统一的 API 来处理分子、蛋白质等科学数据，内置大量面向科学的模型（图神经网络、Transformer 等）和工具，是 AI4Science 领域最成熟的开源项目之一。

## 核心特性

- **科学数据处理**：统一的分子、蛋白质、材料数据加载和预处理管线
- **丰富的模型库**：GAT、GCN、SchNet、DMPNN、ChemBERTa 等科学领域专用模型
- **多任务学习**：支持多任务回归/分类，适应科学数据的多标签特性
- **分子生成**：内置变分自编码器、GAN 等分子生成模型
- **可解释性**：提供梯度可视化和注意力分析等模型解释工具

## 技术栈

- Python
- PyTorch, TensorFlow, JAX
- RDKit (化学信息学)
- Scikit-learn
- DGL (深度图学习)

## 与 Self Evolve 的关联

DeepChem 体现了训练/数据循环和评估器/打分器模式：
- **训练/数据循环**：从实验数据到模型预测再到新实验设计的闭环
- **评估器/打分器**：分子属性预测模型充当评估器，对候选分子进行多维度评分
