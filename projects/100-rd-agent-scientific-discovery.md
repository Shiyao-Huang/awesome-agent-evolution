## 概述

RD-Agent (Research & Development Agent) 是微软研究院开发的 LLM 驱动的科学研究自动化框架。它利用大型语言模型自动提出研究假设、设计实验、分析结果并迭代改进。RD-Agent 可以自动化从数据阅读到模型开发的全流程，已在量化金融、气象预测等领域展现了强大的自动发现能力。

## 核心特性

- **自动假设生成**：LLM 分析数据特征，自动提出研究假设和新因子/模型设计
- **自动实验执行**：生成代码并在目标框架中执行实验
- **结果分析与反馈**：自动分析实验结果，提取改进方向
- **迭代进化**：基于反馈不断改进假设和实现
- **多领域支持**：已应用于量化因子挖掘、天气预报模型优化等领域

## 技术栈

- Python
- 大型语言模型 (GPT-4 / Azure OpenAI)
- QLib (量化金融)
- 自动化实验框架

## 与 Self Evolve 的关联

RD-Agent 是 Self Evolve 范式的最直接体现，综合了多种自我进化模式：
- **进化/搜索循环**：在研究假设空间中搜索最优方案
- **反馈-精炼**：实验结果反馈驱动 LLM 修正假设和代码
- **评估器/打分器**：实验评估指标作为打分信号指导搜索方向
- **反思记忆**：历史实验记录作为上下文记忆，避免重复探索
