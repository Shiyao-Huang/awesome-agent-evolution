## 概述

QLib 是微软亚洲研究院开源的 AI 量化投资平台，覆盖从数据获取、因子挖掘、模型训练到组合优化的完整量化投资流程。它内置多种经典的预测模型（LightGBM、LSTM、Transformer 等）和策略模块，并通过 RD-Agent 实现了 LLM 驱动的自动因子挖掘和模型迭代。

## 核心特性

- **全流程量化框架**：数据处理 -> 因子生成 -> 模型训练 -> 回测 -> 组合优化
- **丰富的模型库**：内置数十种预测模型和策略
- **RD-Agent 集成**：利用 LLM 自动挖掘新的量化因子和研究思路
- **高性能数据引擎**：支持大规模金融数据的高效处理和回测
- **生产级部署**：支持从研究到实盘的全链路部署

## 技术栈

- Python
- PyTorch, LightGBM
- Pandas, NumPy
- LLM API (RD-Agent)

## 与 Self Evolve 的关联

QLib 体现了训练/数据循环和评估器/打分器模式：
- **训练/数据循环**：通过持续的数据更新和模型再训练实现策略迭代
- **评估器/打分器**：回测框架充当评估器，对策略表现打分并指导改进
- **反馈-精炼**：RD-Agent 利用回测反馈自动精炼因子和模型
