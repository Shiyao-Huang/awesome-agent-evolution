## 概述
DeepChem是一个开源的计算化学和生物学AI平台，提供从分子表征、性质预测到药物设计的完整工具链。它是AI在化学和生命科学领域应用最广泛的开源库之一。

## 核心特性
- 丰富的分子表征方法（图神经网络、ECFP、SMILES等）
- 分子性质预测（溶解度、毒性、活性等）
- 药物发现工具（虚拟筛选、分子生成、ADMET预测）
- 支持TensorFlow、PyTorch和JAX后端

## 技术栈
- Python
- PyTorch / TensorFlow / JAX
- RDKit
- NumPy / SciPy
- Scikit-learn

## 与 Self Evolve 的关联
DeepChem为分子发现提供了训练/数据循环的基础设施，支持通过迭代实验和模型训练持续优化分子设计策略。
