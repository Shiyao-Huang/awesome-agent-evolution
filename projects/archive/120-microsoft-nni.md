## 概述
微软的 NNI（Neural Network Intelligence）是 AutoML 平台，支持 NAS、超参数调优和模型压缩，提供 Web UI 可视化实验管理。

## 核心特性
- NAS（DARTS, ENAS, PPO 等）
- 超参数调优（TPE, GA, Bayesian）
- 模型剪枝和量化
- Web UI 实验管理

## 技术栈
- Python, PyTorch, TensorFlow

## 与 Self Evolve 的关联
NNI 是自我进化在 AutoML 中的综合平台：自动搜索最优模型架构和超参数，持续改进模型性能。
