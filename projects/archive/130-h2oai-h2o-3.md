## 概述
H2O.ai 的企业级开源 AutoML 平台，支持分布式训练、自动特征工程、超参数搜索和堆叠集成，是工业界广泛使用的 ML 自动化工具。

## 核心特性
- 企业级分布式 ML 平台
- 自动特征工程和模型选择
- 堆叠集成（Stacked Ensemble）
- Web UI + Python/R/REST API 接口

## 技术栈
- Java, Python, R, Spark

## 与 Self Evolve 的关联
H2O-3 在企业规模上实现了"自动搜索→评估→集成"的 ML 自动化，是自我进化在工业级 ML 中的应用范例。
