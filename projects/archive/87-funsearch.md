# FunSearch - LLM 数学发现
- **仓库**: google-deepmind/funsearch
- **GitHub**: https://github.com/google-deepmind/funsearch
- **Stars**: 1500
- **语言**: Python
- **许可**: Apache-2.0

- **模式**: 进化/搜索循环 → 评估器/打分器

## 概述
DeepMind 的 FunSearch，用 LLM + 岛屿模型进化搜索发现数学新知识，首个在数学开放问题上超越人类已知的 LLM 系统。

## 核心特性
- LLM 生成程序变体
- 岛屿模型进化搜索
- 自动评估器验证发现
- 超越人类已知的数学结果

## 技术栈
- Python, Google PaLM 2

## 与 Self Evolve 的关联
FunSearch 是"进化/搜索循环+评估器"在科学发现中的典型应用：LLM 生成候选方案→评估器筛选→进化保留最优。
