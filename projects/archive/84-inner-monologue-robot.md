## 概述

Inner Monologue 是 Google Research 提出的具身推理框架，让机器人在执行任务时通过"内心独白"的方式进行自我对话和推理。智能体将感知反馈（如物体识别结果、操作成功/失败状态）转化为自然语言描述，作为上下文输入给 LLM，使 LLM 能够像人类一样在行动中思考和调整策略。

## 核心特性

- **内省式推理**：智能体在任务执行过程中持续生成自我对话
- **多模态反馈转文本**：将视觉、触觉等感知反馈转化为 LLM 可理解的语言描述
- **闭环规划**：基于执行反馈动态调整后续动作序列
- **场景描述理解**：利用场景理解能力将环境状态编码为自然语言

## 技术栈

- Python
- 大型语言模型 (PaLM)
- 视觉-语言模型 (场景描述)
- 机器人技能策略库

## 与 Self Evolve 的关联

Inner Monologue 是反思记忆和反馈-精炼模式的结合：
- **反思记忆**：通过内省式自我对话记录和反思执行过程
- **反馈-精炼**：将环境反馈转化为语言反馈，驱动 LLM 精炼后续策略

## 分类

具身智能体方向中的内省式推理框架，属于「语言模型驱动的机器人自我反思」。
