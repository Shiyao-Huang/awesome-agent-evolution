## 概述
Dora-rs 是高性能的机器人数据流编排框架，用 Rust 编写核心，支持 Python/C++ 节点，提供低延迟的传感器-算法-执行器数据管线。

## 核心特性
- Rust 零拷贝数据流引擎
- 支持 Python/C++/ROS2 节点
- 声明式数据流配置
- 低延迟、高吞吐量

## 技术栈
- Rust, Python, C++, Apache Arrow

## 与 Self Evolve 的关联
Dora-rs 为具身智能的自我进化提供了数据流编排基础设施，使感知-决策-执行循环高效运行。
