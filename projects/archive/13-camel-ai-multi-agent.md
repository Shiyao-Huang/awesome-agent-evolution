## 概述
CAMEL（Communicative Agents for Mind Exploration of Large Language Model Society）是一个专注于多Agent通信与协作的研究框架，致力于探索大语言模型社会中Agent之间的交互行为。它提出了角色扮演（Role-Playing）范式，使Agent能够在特定场景中进行深度对话与协作。

## 核心特性
- 角色扮演通信范式：支持定义不同角色的Agent进行结构化对话，模拟社会交互
- 多种Agent能力：支持检索增强生成（RAG）、代码执行、工具调用等复合能力
- 可扩展的Agent社会：支持构建多Agent社会模拟，研究群体智能与涌现行为
- 丰富的基准测试：内置多种多Agent交互评估基准和数据集
- 模块化架构：Agent、消息、记忆、工具等组件高度解耦，便于定制

## 技术栈
- Python 3.8+
- OpenAI API / Anthropic API / 开源模型
- Gradio（Web界面）
- Vector Database（RAG支持）
- LangChain（可选集成）

## 与 Self Evolve 的关联
CAMEL 的角色扮演通信范式为自我进化系统提供了Agent间知识传递和协作优化的理论基础，其社会模拟能力可用于研究多Agent系统中的进化策略和群体智能涌现机制。
