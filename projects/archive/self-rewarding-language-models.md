## 1. 任务定义

Self-Rewarding 解决的核心瓶颈是：当奖励模型（RM）冻结时，语言模型的自我改进会在几个迭代后饱和。该工作提出让同一个模型同时充当策略模型和奖励模型（通过 LLM-as-a-Judge），使指令遵循能力和奖励建模能力通过迭代 DPO 训练联合提升。这打破了对外部冻结奖励模型的依赖，为持续自我改进开辟了路径。从 Llama 2 70B 出发，仅用 3,200 个 IFT 种子样本和 1,630 个 EFT 种子样本，三轮迭代后超越了 Claude 2、Gemini Pro 和 GPT-4 0613。

## 2. 方法核心

### 2.1 改进对象
可变状态为模型权重 θ。同一个 LLM（Llama 2 70B）同时承担两个角色：指令遵循（策略）和响应评估（奖励模型）。两个能力通过同一组权重编码。初始化为 M0 -> M1（在 IFT 指令数据 + EFT 评估数据上 SFT）。

### 2.2 变异算子 U
迭代 DPO 训练：(1) 模型为每个提示生成 N=4 个候选响应（采样 T=0.7, p=0.9）；(2) 使用 LLM-as-a-Judge（5 分制，5 个加性标准：相关性、覆盖度、有用性、清晰度、专业性）对每个候选评估，评分取 3 次采样平均以降低方差；(3) 最高分响应为 chosen，最低分为 rejected，同分对丢弃；(4) 在 AIFT 数据上训练 M(t+1)（初始化自 Mt），DPO 超参：lr 1e-6->1e-7, batch 16, beta=0.1。

### 2.3 适应度函数 V
自我评估：模型使用 LLM-as-a-Judge 提示模板评估自身生成的响应。5 点加性评分标准（非多选题桶）产生更具区分度的评估——论文显示该设计达到 65.1% 的成对准确率，而多选提示仅 26.6%。评分使用 5 个加性标准而非单一直觉评分。

### 2.4 选择机制 S
基于自我评分的偏好对构造：从 N=4 候选中选最高分为正例、最低分为负例。迭代序列为 M0（基座）-> M1（IFT+EFT SFT）-> M2（AIFT(M1) DPO，3,964 对）-> M3（AIFT(M2) DPO，6,942 对）。使用 Claude 2 在验证集上进行早停。

### 2.5 闭环结构
训练轨迹为：基座模型 -> SFT（3,200 IFT 指令 + 1,630 EFT 评估）-> 迭代 DPO 循环（自生成候选 -> 自评估 -> 偏好对 -> DPO 训练）。奖励模型能力在迭代间自发提升（成对准确率从 78.7% -> 80.4% -> 81.7%），无需额外 EFT 数据。核心正反馈循环为：更好的指令遵循 -> 更好的评估能力 -> 更高质量的偏好数据 -> 进一步改进。

## 4. 定性判断

### 4.1 限制
- 长度偏差：模型生成长度从 M1 到 M3 增长 2.34 倍（1092->2552 tokens），部分改进可能是长度伪影而非真实质量提升
- 奖励黑客风险：同一模型生成和评估响应，可能学会生成在自身标准下高分但非真正更好的响应
- 推理任务改进有限：数学、编码和逻辑推理的提升显著低于人文和写作任务
- 仅 3 轮迭代验证：未探索缩放规律——多少迭代后出现收益递减或退化
- 对齐税：标准 NLP 基准（ARC, HellaSwag, MMLU）出现轻微退化
- 评估循环性：训练和基准评估都使用 LLM-as-a-Judge 范式
- 安全影响未探索：模型能否学会对有害内容给予高奖励

### 4.2 适用场景
- 指令遵循能力的自我改进训练
- 缺乏外部奖励模型或人类标注资源的场景
- 从少量种子数据启动的自我对弈训练
- 写作和人文领域的对齐优化

### 4.3 教学价值
- 统一模型的双重角色（策略 + 奖励）是双轴自我改进的直接示范
- 打破人类反馈瓶颈：自生成偏好数据可产生与百万级专有标注训练的模型竞争的结果
- 迭代 DPO（自评估 + 偏好对构造 + DPO）是实用且可实现的自我进化框架
- 长度偏差是自进化系统的普遍隐患：任何使用自生成奖励的系统都必须考虑此问题
- 种子数据质量很重要：对推理任务的局限可能源于 Open Assistant 种子数据的分布


EFT 数据的添加对 IFT 性能的影响微乎其微（30.5% vs 30.9% win rate），确认了模型可以同时学习评估和生成而不互相干扰。这一发现对自进化系统设计很重要：它意味着评估能力和执行能力可以共享同一组权重。

在方法谱系中，Self-Rewarding 是 Meta-Rewarding 和后续自我改进工作的直接基础。它建立的"统一策略-奖励模型"范式已被广泛采纳。与 RLHF（Ouyang et al., 2022）相比，它移除了对外部奖励模型的依赖；与 Constitutional AI（Bai et al., 2022）相比，它统一了 judge 和 policy 而非使用单独的反馈模型。STaR（Zelikman et al., 2022）在推理任务上使用了类似的迭代自改进范式，但 Self-Rewarding 将其扩展到了指令遵循和奖励建模。

## 5. 与自进化的关系

Self-Rewarding 在 L1-L5 分类中属于 L2（权重级自我改进）。进化对象是模型权重 θ，通过 DPO 梯度更新实现变异。满足 (M)(U)(V)(S) 四要素，但 V（适应度函数）和 U（变异算子）共享同一组权重，创造了自我参照的评估循环。这是该方法最大的创新点也是最根本的风险——奖励建模能力从 78.7% 提升到 81.7% 证明了自我改进的有效性，但长度增长 2.34 倍和 MMLU 下降警示了自我确认偏差。对未来自进化系统的核心启示是：当模型同时充当执行者和评估者时，两个维度的能力可以联合提升，但评估独立性是防止退化的关键约束。Meta-Rewarding 直接继承了这一框架并增加了 meta-judge 角色来解决评估器质量瓶颈。

计算需求：训练 Llama 2 70B 通过多轮 DPO 需要约 8xA100 级 GPU。每迭代涉及约 4K-7K 偏好对（每对 4 候选 x 3 次评估）的生成和 70B 模型的 DPO 训练。种子数据来自公开的 Open Assistant 数据集。

论文发表于 ICML 2024，经过同行评审，增加了方法可信度。Self-Rewarding 建立的范式已成为后续自我改进研究（包括 Meta-Rewarding）的标准基线。
