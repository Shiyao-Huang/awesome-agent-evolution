# FLAML - 快速轻量 AutoML
- **仓库**: microsoft/FLAML
- **GitHub**: https://github.com/microsoft/FLAML
- **Stars**: 4354
- **语言**: Python
- **许可**: MIT
- **最近活跃**: 2026-04
- **模式**: 进化/搜索循环 → 评估器/打分器

## 概述
微软的快速轻量 AutoML 库，使用经济学搜索策略（CFO + BlendSearch）在有限预算内高效找到好的模型配置，支持 AutoML、AutoGen 和超参数调优。

## 核心特性
- 经济学搜索策略（CFO + BlendSearch）
- 支持分类/回归/时序/NLP 任务
- 极低计算资源消耗
- AutoGen Agent 框架集成

## 技术栈
- Python, scikit-learn, XGBoost, LightGBM

## 与 Self Evolve 的关联
FLAML 的低成本高效搜索为自我进化系统提供了"资源受限下的智能搜索"范式。
