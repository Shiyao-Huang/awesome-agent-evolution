## 概述
Google Research 的 Code as Policies 方法，让 LLM 生成 Python 代码作为机器人控制策略，通过代码的合成、执行和反馈实现灵活的机器人操作。

## 核心特性
- LLM 生成可执行 Python 代码
- 代码即策略（Code = Policy）
- API 调用驱动机器人动作
- 支持复杂逻辑和循环控制

## 技术栈
- Python, OpenAI API, Google PaLM

## 与 Self Evolve 的关联
Code as Policies 展示了代码生成作为自我进化工具在具身智能中的应用：生成的代码可被验证、修改和迭代改进。
