## 概述
Continue 是一个开源的AI代码助手，以IDE插件的形式集成到VS Code和JetBrains等开发环境中。它支持代码补全、自然语言编辑、代码解释和错误修复等功能，允许开发者在不离开编辑器的情况下与AI进行交互式协作。

## 核心特性
- IDE 深度集成：支持VS Code、JetBrains全家桶等主流IDE
- 多模型后端：支持OpenAI、Anthropic、本地模型（Ollama）等多种LLM
- 上下文感知：自动收集当前文件、相关文件和项目结构作为代码上下文
- 可配置的提示词：支持自定义提示词模板，针对不同场景优化AI行为
- 斜杠命令系统：通过斜杠命令快速触发代码编辑、解释、文档生成等操作
- Tab 自动补全：提供类似Copilot的实时代码补全功能

## 技术栈
- TypeScript
- VS Code Extension API / JetBrains Plugin API
- OpenAI / Anthropic / Ollama（多模型后端）
- Node.js（运行时）

## 与 Self Evolve 的关联
Continue 的人机交互式代码改进流程展示了自我进化系统在实际开发场景中的应用范式——开发者的即时反馈和修改操作为AI提供了高质量的训练信号，这种持续的人机协作循环是实现代码层面自我改进的有效路径。
