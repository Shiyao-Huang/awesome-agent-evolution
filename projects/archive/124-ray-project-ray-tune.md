# Ray Tune - 分布式超参数调优
- **仓库**: ray-project/ray

## 概述
Ray Tune 是 Ray 生态中的分布式超参数调优库，支持 ASHA、HyperBand、Bayesian 等搜索算法，可无缝扩展到数百个并行试验。

## 核心特性
- ASHA/HyperBand/PBT/Bayesian 搜索
- 大规模分布式试验
- 自动 GPU 分配
- 与 Optuna/HyperOpt 集成

## 技术栈
- Python, Ray

## 与 Self Evolve 的关联
Ray Tune 为自我进化系统提供了大规模分布式搜索的基础设施，支持并行评估大量候选方案。
