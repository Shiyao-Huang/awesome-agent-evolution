# Auto-sklearn - 自动化 ML 框架
- **仓库**: automl/auto-sklearn
- **GitHub**: https://github.com/automl/auto-sklearn
- **Stars**: 8104
- **语言**: Python
- **许可**: Apache-2.0

- **模式**: 进化/搜索循环 → 评估器/打分器

## 概述
基于 scikit-learn 的自动化 ML 框架，通过贝叶斯优化+元学习自动选择模型、特征预处理和超参数，是 AutoML 领域的标杆项目。

## 核心特性
- 贝叶斯超参数优化
- 元学习热启动
- 自动特征预处理管线
- 集成选择（Ensemble Selection）

## 技术栈
- Python, scikit-learn, ConfigSpace, SMAC

## 与 Self Evolve 的关联
Auto-sklearn 的"自动搜索→评估→集成"流程是自我进化在 ML 系统中的体现：自动搜索最优配置并持续改进。
