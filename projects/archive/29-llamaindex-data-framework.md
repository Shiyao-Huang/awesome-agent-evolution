## 概述
LlamaIndex 是一个面向大语言模型的数据框架，专注于将企业数据与LLM高效连接。它提供了数据摄取、索引构建、检索增强生成（RAG）和多Agent编排的完整工具链，是构建数据驱动的LLM应用的核心基础设施。

## 核心特性
- 数据连接器生态：支持160+种数据源的摄取，包括数据库、文档、网页、API等
- 多种索引结构：提供向量索引、关键词索引、知识图谱索引等多种检索策略
- 高级RAG流水线：支持查询变换、路由、重排序等高级RAG技术
- Agent框架：内置支持ReAct、Plan-and-Solve等多种Agent模式
- 多Agent工作流：支持构建多Agent协作系统，包括Agent间的工具共享和状态传递

## 技术栈
- Python 3.8+ / TypeScript
- 多种向量数据库（Pinecone、Weaviate、Chroma等）
- OpenAI / Anthropic / 开源模型
- LangChain（互补集成）
- PostgreSQL（结构化存储）

## 与 Self Evolve 的关联
LlamaIndex 的数据框架为自我进化系统提供了知识管理的基础设施——进化过程中的经验、策略和中间结果需要高效存储和检索，其多Agent编排能力也支持构建具有知识积累和传递机制的进化系统。
