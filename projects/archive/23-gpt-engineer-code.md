## 概述
GPT-Engineer 是一个面向自然语言代码生成的开源工具，用户通过描述想要构建的功能，系统自动生成完整的代码项目。它以简单直接的方式展示了LLM在代码生成领域的强大能力，并支持通过反馈迭代逐步改进生成的代码。

## 核心特性
- 自然语言到代码：用户用自然语言描述需求，系统自动生成对应的完整代码项目
- 交互式精炼：支持用户对生成的代码提出修改意见，系统据此迭代改进
- 项目结构生成：不仅生成代码文件，还包括配置文件、依赖说明等完整项目结构
- 多种生成模式：支持从零创建项目、迭代改进现有项目、以及代码解释等模式
- 预置提示词模板：包含多种优化的提示词模板，提升代码生成质量

## 技术栈
- Python 3.8+
- OpenAI API（核心LLM）
- Anthropic API（可选）
- Terraform（基础设施代码生成）

## 与 Self Evolve 的关联
GPT-Engineer 的交互式代码精炼流程展示了自我进化系统中人机协作的改进模式——通过自然语言反馈引导代码质量的持续提升，这种反馈驱动的迭代机制是构建能够自我改进的代码生成系统的关键要素。
