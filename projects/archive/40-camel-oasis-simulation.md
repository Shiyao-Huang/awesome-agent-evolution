## 概述
CAMEL Oasis 是基于CAMEL框架的多Agent社会模拟平台，旨在研究大规模Agent社会中涌现的群体行为和社会现象。它提供了模拟社交网络、经济交易、信息传播等社会过程的实验环境，用于探索AI Agent群体中的协作、竞争和进化行为。

## 核心特性
- 大规模社会模拟：支持数百到数千个Agent组成的人工社会
- 多种社会场景：支持社交网络、市场经济、信息传播等多种社会模拟场景
- 行为观测与分析：提供Agent行为追踪、社会网络分析和统计可视化工具
- 自主Agent角色：每个Agent拥有独立的记忆、偏好和决策能力
- 可扩展的模拟框架：支持自定义社会规则、Agent行为策略和评估指标

## 技术栈
- Python 3.8+
- CAMEL Framework（Agent基础设施）
- OpenAI API / 开源模型
- NetworkX（社交网络分析）
- Matplotlib / Plotly（可视化）

## 与 Self Evolve 的关联
CAMEL Oasis 的大规模社会模拟为研究多Agent系统中的进化动力学提供了实验环境——通过模拟Agent群体中的选择、变异和遗传过程，可以观察进化策略在群体层面的涌现行为，为设计群体级自我进化系统提供理论依据。
