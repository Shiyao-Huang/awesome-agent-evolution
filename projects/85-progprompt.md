## 概述
Google Research 的 ProgPrompt 方法，将机器人任务规划转化为结构化的程序化提示（Programmatic Prompt），让 LLM 生成包含条件分支和循环的机器人执行计划。

## 核心特性
- 程序化提示（Programmatic Prompting）
- 条件分支和循环控制结构
- 环境状态感知
- 嵌套技能组合

## 技术栈
- Python, LLM API

## 与 Self Evolve 的关联
ProgPrompt 展示了自我进化中"结构化编程思维"的应用：将任务分解为可组合、可验证的程序化步骤。
