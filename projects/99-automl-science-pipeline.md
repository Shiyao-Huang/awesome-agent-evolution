## 概述

Auto-sklearn 是弗莱堡大学自动化机器学习 (AutoML) 团队开发的开源自动机器学习框架，是 NIPS 2015 AutoML 挑战赛的获胜方案。它通过贝叶斯超参数优化、元学习和自动化模型集成等技术，实现了从数据预处理到模型选择的完整自动化管线，极大降低了科学研究中使用机器学习的门槛。

## 核心特性

- **自动化管线**：数据预处理 -> 特征工程 -> 模型选择 -> 超参数优化的全自动流程
- **贝叶斯优化**：使用 SMAC 算法进行高效的超参数搜索
- **元学习**：利用历史数据集的经验快速初始化搜索
- **自动集成**：构建多模型集成提升最终性能
- **scikit-learn 兼容**：完全兼容 scikit-learn 的 API 和工作流

## 技术栈

- Python
- scikit-learn
- SMAC3 (贝叶斯优化)
- ConfigSpace (配置空间定义)
- Pandas, NumPy

## 与 Self Evolve 的关联

Auto-sklearn 是进化/搜索循环和反馈-精炼的自动化实现：
- **进化/搜索循环**：在模型和超参数空间中搜索最优组合
- **反馈-精炼**：每轮评估的性能反馈驱动贝叶斯优化器调整搜索策略
