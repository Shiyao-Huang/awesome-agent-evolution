## 概述
NNI（Neural Network Intelligence）是微软亚洲研究院开发的自动机器学习工具包，提供超参数调优、神经架构搜索、模型压缩等自动化功能。它支持本地、远程和分布式训练环境，拥有直观的 Web UI 用于监控和管理实验。

## 核心特性
- 全面的调优算法：贝叶斯优化、TPE、Hyperband、进化算法等 20+ 调优器
- 神经架构搜索：支持 ENAS、DARTS、PDPNAS、SPOS 等 NAS 算法
- 模型压缩：自动剪枝和量化
- Web UI 可视化：实时监控实验进度和结果
- 多平台支持：本地、远程服务器、Kubernetes、AML

## 技术栈
- Python, PyTorch, TensorFlow
- Kubernetes (分布式)
- Web UI (可视化)

## 与 Self Evolve 的关联
NNI 将超参数调优、架构搜索和模型压缩整合为统一的自动化平台，代表了 AI 系统在训练全流程上的自我优化能力，是构建端到端自我进化 AI 系统的重要工具。
