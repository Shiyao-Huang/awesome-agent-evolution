## 概述

FunSearch 是 Google DeepMind 开发的一种利用 LLM 进行数学和科学发现的方法，发表于 Nature 2023。它通过进化搜索的方式，让 LLM 不断生成、评估和改进计算机程序，从而发现超越人类已知最优解的数学构造。FunSearch 是首个利用 LLM 在数学和计算机科学领域做出新科学发现的工作。

## 核心特性

- **LLM 进化搜索**：LLM 作为变异算子，不断生成新的候选程序
- **程序评估器**：自动评估 LLM 生成的程序质量和正确性
- **进化策略**：保留最优程序，以它们为种子让 LLM 继续变异生成新程序
- **可解释发现**：输出的不是黑箱结果，而是可读的计算机程序

## 技术栈

- Python
- 大型语言模型 (Codey / PaLM)
- 进化算法框架
- 数学评估器

## 与 Self Evolve 的关联

FunSearch 是进化/搜索循环和反馈-精炼模式的完美结合：
- **进化/搜索循环**：LLM 生成候选程序 -> 评估器打分 -> 保留最优 -> 以最优为种子继续进化
- **反馈-精炼**：评估结果作为反馈，指导 LLM 改进生成的程序
