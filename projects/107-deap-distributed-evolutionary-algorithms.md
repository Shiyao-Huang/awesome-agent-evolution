# DEAP - 分布式进化算法框架
- **仓库**: DEAP/deap
- **GitHub**: https://github.com/DEAP/deap
- **Stars**: 6401
- **语言**: Python
- **许可**: LGPL-3.0
- **最近活跃**: 2025-11
- **模式**: 进化/搜索循环

## 概述
DEAP 是最成熟的开源进化计算框架之一，提供 GA、GP、ES、PSO、MOEA 等多种进化算法的模块化实现，支持并行化和自定义算子。

## 核心特性
- GA/GP/ES/PSO/MOEA 等丰富算法
- 模块化算子设计（可自由组合）
- Scoop/Multiprocessing 并行支持
- 自适应算子概率

## 技术栈
- Python, NumPy

## 与 Self Evolve 的关联
DEAP 是自我进化系统中进化/搜索循环的基础工具库，提供了丰富的变异、交叉和选择算子。
