# Optuna - 超参数优化框架
- **仓库**: optuna/optuna
- **GitHub**: https://github.com/optuna/optuna
- **Stars**: 11000
- **语言**: Python

- **模式**: 进化/搜索循环 → 评估器/打分器

## 概述
Preferred Networks 的超参数优化框架，提供 TPE、CMA-ES、GP 等多种搜索算法，支持剪枝和分布式优化，是 ML 实验管理的标准工具。

## 核心特性
- TPE/CMA-ES/GP/Multi-objective 搜索
- 自动早停（Pruning）
- 分布式优化
- 丰富的可视化仪表盘

## 技术栈
- Python, NumPy, SciPy

## 与 Self Evolve 的关联
Optuna 的"搜索→评估→剪枝→再搜索"是自我进化中"进化/搜索循环"的工程化实现。
