## 概述
Embodied Agents是一个基于大语言模型的机器人智能体框架，提供模块化的感知-规划-执行管线。它将LLM的推理能力与机器人控制系统结合，支持通过自然语言指令控制真实和模拟机器人。

## 核心特性
- 模块化感知-规划-执行架构
- 支持多种LLM后端（GPT-4、Claude等）
- 与多种机器人平台和模拟器集成
- 自然语言到机器人动作的端到端映射

## 技术栈
- Python
- ROS2
- OpenAI API
- PyBullet
- OpenCV

## 与 Self Evolve 的关联
该框架展示了LLM如何作为机器人系统的中央推理引擎，通过持续的感知-行动循环实现智能体行为的自主进化。
