## 概述
纯 Python 实现的遗传算法库，提供清晰的 GA 流程实现（选择、交叉、变异、精英保留），适合教学和快速原型开发。

## 核心特性
- 纯 Python 无外部依赖
- 选择/交叉/变异/精英保留完整流程
- 支持二进制和实数编码
- 丰富的示例（函数优化、图像重建等）

## 技术栈
- Python, NumPy

## 与 Self Evolve 的关联
GA 是自我进化中"进化/搜索循环"的基础算法，本项目提供了简洁易懂的实现参考。
