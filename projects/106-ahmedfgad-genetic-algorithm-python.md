## 概述
GeneticAlgorithmPython 是一个功能丰富的遗传算法 Python 库，提供了从基础遗传操作（选择、交叉、变异）到高级特性（自适应 mutation、多目标优化）的完整实现。该库设计简洁，API 友好，适合教学和实际应用。

## 核心特性
- 完整的遗传算法流程：选择（tournament、roulette）、交叉（单点、多点、均匀）、变异
- 灵活的编码方式：支持二进制、实数、排列等多种编码
- 自适应参数控制：根据进化进度自动调整变异率和交叉率
- NumPy 加速：核心操作使用 NumPy 实现以保证性能

## 技术栈
- Python, NumPy
- PyGAD (高级封装)

## 与 Self Evolve 的关联
遗传算法是 AI 自我进化最基础和最经典的方法之一，该库提供了 GA 的完整实现范式，展示了如何通过选择压力和遗传变异实现自动化搜索优化。
