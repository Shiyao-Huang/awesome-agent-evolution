## 概述
Langflow 是一个面向LangChain生态的可视化Agent编排平台，提供拖拽式的流程设计器，支持构建复杂的Agent工作流、RAG流水线和多Agent系统。它在保持可视化易用性的同时，提供了面向开发者的代码级定制能力。

## 核心特性
- 可视化流程设计器：直观的拖拽界面，支持LangChain全部组件的视觉化配置
- Python 代码导出：可将可视化流程直接导出为可运行的Python代码
- 自定义组件：支持编写自定义Python组件并集成到可视化界面
- 多Agent编排：支持构建包含多个Agent、工具和记忆的复杂系统
- 实时调试与测试：内置聊天测试界面和流程调试工具

## 技术栈
- Python 3.9+
- React（前端界面）
- LangChain（核心引擎）
- FastAPI（后端API）
- SQLAlchemy（数据管理）
- Docker（部署）

## 与 Self Evolve 的关联
Langflow 的可视化编排与代码导出的双重能力，为自我进化系统提供了从快速原型到生产部署的完整路径。其自定义组件机制使得进化过程中产生的新策略和新工具可以即时注册为可视化组件，实现系统的自我扩展。
