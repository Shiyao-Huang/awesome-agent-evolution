## 概述
Self-Evolve 是 OpenBMB 团队提出的代码自我进化框架，实现了 LLM 在代码生成任务上的自主改进闭环。框架核心流程为：给定编程问题，模型生成初始代码 -> 模型自身执行代码并进行调试 -> 模型根据执行反馈修复错误 -> 迭代直到代码通过所有测试。Self-Evolve 通过这种"生成-执行-反馈-修复"的闭环，使模型能够自主地提升代码生成能力，无需人类干预。

## 核心特性
- **自动执行反馈**: 自动运行生成的代码并收集执行结果和错误信息
- **自我调试**: 模型根据执行错误信息自主修复代码
- **多轮迭代**: 支持多轮生成-执行-修复循环
- **测试用例驱动**: 使用测试用例作为正确性验证标准
- **自我进化闭环**: 修复经验积累到模型中，实现能力持续提升
- **多种编程语言**: 支持 Python 等多种编程语言

## 技术栈
- Python, LLM API (GPT-4 / 开源模型)
- 代码执行沙箱
- 单元测试框架

## 与 Self Evolve 的关联
OpenBMB Self-Evolve 是 Self Evolve 系统中"反馈-精炼"模式在代码生成领域的直接体现。其"生成-执行-反馈-修复"闭环是自我进化的典型模式。代码执行结果提供了客观、自动化的反馈信号，使得自我进化不依赖人类判断。这种通过环境反馈驱动的自我进化范式，可扩展到其他具有自动验证机制的领域。
