- **模式**: 训练/数据循环

## 概述
iGibson是斯坦福大学开发的交互式3D仿真环境，支持在真实家庭场景中进行物体交互、导航和操作任务。它提供丰富的物体交互物理模拟，是Behavior基准测试的核心仿真平台。

## 核心特性
- 基于真实家庭场景的3D环境（15个高质量场景、1000+交互物体）
- 精确的物体级物理模拟和状态变化
- 支持导航、操作、物体交互等多种任务
- 与BEHAVIOR基准测试深度集成

## 技术栈
- C++
- Python
- PyBullet
- OpenGL
- NumPy

## 与 Self Evolve 的关联
iGibson为具身智能体提供了丰富的交互环境，支持智能体通过与环境的持续交互来进化更复杂的操作和规划能力。
