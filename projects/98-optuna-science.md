# Optuna - 科学超参数优化框架
- **仓库**: optuna/optuna

## 概述
Optuna是一个自动超参数优化框架，通过高效的搜索算法和剪枝策略帮助科研人员和工程师找到最优模型配置。它支持定义-运行的API设计，广泛应用于科学计算和机器学习实验。

## 核心特性
- 多种采样算法（TPE、CMA-ES、NSGA-II等）
- 自动早停剪枝（Median、Hyperband等）
- 分布式优化和实验管理
- 丰富的可视化仪表板和实验追踪

## 技术栈
- Python
- NumPy / SciPy
- SQLAlchemy
- Plotly (可视化)
- Alembic

## 与 Self Evolve 的关联
Optuna通过搜索循环自动探索最优配置空间，其高效的超参数搜索策略是AI系统自我优化和进化过程中的关键基础设施。
