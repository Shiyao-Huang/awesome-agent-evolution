# LLM-Adaptive-Testing - LLM自适应测试
- **仓库**: microsoft/LLM-Adaptive-Testing
- **GitHub**: https://github.com/microsoft/LLM-Adaptive-Testing
- **Stars**: ~100
- **语言**: Python
- **许可**: MIT
- **最近活跃**: 2024-08
- **模式**: 评估器/打分器

## 概述
微软研究院推出的LLM自适应测试框架，通过智能选择和调整测试用例来高效评估大语言模型的能力。该方法根据模型当前表现动态调整测试难度和范围，在减少测试成本的同时提高评估的准确性和全面性。

## 核心特性
- 自适应测试用例选择和难度调整
- 基于模型表现的动态评估策略
- 显著减少评估所需的测试样本数量

## 技术栈
- Python, PyTorch, Hugging Face Transformers

## 与 Self Evolve 的关联
自适应测试为自我进化系统提供了高效的评估机制，使模型能够在进化过程中快速定位能力短板并进行针对性改进，是构建高效自我进化评估反馈循环的重要组成部分。
