## 概述
DeepMind 的 Android 交互式 RL 环境，让智能体在真实 Android 系统中学习操作应用，是 GUI Agent 研究的重要基础设施。

## 核心特性
- 真实 Android 系统交互
- 支持 UI 操作和屏幕观察
- 标准化 RL 接口（gym.Env）
- 多任务评估框架

## 技术栈
- Python, Android SDK, dm_env

## 与 Self Evolve 的关联
Android Env 为自我进化系统提供了真实的 GUI 交互环境，智能体可在应用操作中观察结果、诊断错误、自我改进。
