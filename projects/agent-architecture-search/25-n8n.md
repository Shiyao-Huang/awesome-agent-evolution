## 核心定位

n8n 是面向技术团队的安全工作流自动化平台。提供 400+ 集成、原生 AI 能力和 fair-code 许可证。支持代码和可视化混合开发模式，是 2026 年 AI Agent 工作流编排的重要基础设施。

## 技术架构

### Monorepo 结构 (pnpm workspaces + Turbo)

```
packages/workflow     — 核心工作流接口和类型
packages/core         — 工作流执行引擎
packages/cli          — Express 服务器 + REST API + CLI
packages/editor-ui    — Vue 3 前端
packages/@n8n/api-types — 前后端共享接口
packages/nodes-base   — 内置集成节点（400+）
packages/@n8n/nodes-langchain — AI/LangChain 节点
packages/@n8n/instance-ai — AI 助手后端
@n8n/design-system    — Vue 组件库
@n8n/config           — 集中配置管理
```

### 核心技术栈

- **前端**: Vue 3 + TypeScript + Vite + Pinia
- **后端**: Node.js + TypeScript + Express + TypeORM
- **测试**: Jest (单元) + Playwright (E2E)
- **数据库**: SQLite/PostgreSQL
- **代码质量**: Biome + ESLint + lefthook

### 关键架构模式

1. **依赖注入** — `@n8n/di` IoC 容器
2. **Controller-Service-Repository** — MVC 模式
3. **事件驱动** — 内部事件总线
4. **基于上下文的执行** — 不同节点类型不同上下文
5. **设计系统** — `@n8n/design-system` 统一 UI

## AI 能力

### AI/LangChain 集成

- **AI Agent 节点** — 内置 LangChain 支持
- **多 Agent 编排** — 对话管理 + 检索增强
- **自定义模型** — 支持所有主流 LLM
- **向量数据库集成** — RAG 工作流

### AI 开发工作流

- `pnpm dev:ai` — AI 功能专用开发模式
- 专用节点开发工具
- Playwright 测试自动化

## Self Evolve 关联

### 直接关联

- **Agent 工作流编排**: n8n 的节点化工作流为 Agent 自进化提供了可视化编排基础设施
- **AI Agent 节点**: 内置 LangChain 节点使 Agent 部署和测试更便捷
- **400+ 集成**: 丰富的工具生态为 Agent 技能进化提供了接口

### 间接关联

- **工作流即代码**: 工作流的 JSON 表示可版本控制，支持工作流的"进化"
- **MCP 服务器**: 可将工作流部署为 MCP 服务器，成为其他 Agent 的工具
- **模板生态**: 900+ 模板是集体智慧的结晶
