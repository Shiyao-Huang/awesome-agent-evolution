## 核心定位

DeepSeek-V3 是一个 671B 参数的 Mixture-of-Experts (MoE) 语言模型，每次推理激活 37B 参数。它在性能上超越其他开源模型，达到闭源领先模型水平，而训练成本仅 2.788M H800 GPU 小时。

## 模型架构创新

### 核心架构

- **Multi-head Latent Attention (MLA)** — 继承自 DeepSeek-V2
- **DeepSeekMoE** — 高效 MoE 架构
- **无辅助损失负载均衡** — 首创不依赖辅助损失的负载均衡策略
- **多 Token 预测 (MTP)** — 同时预测多个 token，提升性能 + 推理加速

### 训练创新

| 特性 | 详情 |
|------|------|
| **训练数据** | 14.8 万亿 tokens |
| **精度** | FP8 混合精度训练（首次在超大规模模型验证） |
| **训练成本** | 2.664M H800 GPU 小时（预训练） |
| **稳定性** | 全程无不可恢复的 loss spike，无需回滚 |
| **通信优化** | 近完全的计算-通信重叠 |

### 后训练

- 从 DeepSeek-R1 知识蒸馏
- SFT + RL 后训练阶段仅需 0.1M GPU 小时

## Self Evolve 关联

### 直接关联

- **自改进推理**: DeepSeek-R1 的推理能力通过蒸馏传递给 V3，体现了"强者自我进化"的范式
- **高效训练**: 极低的训练成本使得反复迭代进化成为可能
- **FP8 训练框架**: 降低自进化过程的计算门槛

### 间接关联

- **开源基础模型**: 为下游 Agent 自进化研究提供低成本、高性能的基础
- **MoE 架构**: 动态激活机制与 Agent 的条件执行模式类似
- **MTP 目标**: 多 token 预测可类比于 Agent 的多步规划能力

## 技术影响

1. **FP8 训练的里程碑** — 首次证明 FP8 在超大规模模型上的可行性
2. **无辅助损失负载均衡** — 解决了 MoE 训练的长期痛点
3. **极致成本效率** — 证明了开源模型可以用极低成本达到前沿水平
4. **知识蒸馏链** — R1 → V3 的蒸馏路径为模型自进化提供了范例
