## 概述
Mava是InstaDeep开发的多智能体强化学习（MARL）框架，基于JAX构建，提供高效分布式训练能力。它支持多种主流多智能体算法，旨在为复杂的多智能体协作和竞争问题提供研究基础设施。

## 核心特性
- 基于JAX的高性能分布式多智能体训练
- 支持多种MARL算法（MAPPO、QMIX、IDDPG等）
- 灵活的系统架构，支持自定义环境和网络
- 与JAX生态系统深度集成（Optax、Haiku等）

## 技术栈
- Python
- JAX
- Optax
- Haiku / Flax
- Docker

## 与 Self Evolve 的关联
Mava为多智能体系统的协同进化提供了训练框架，多个智能体通过交互和反馈持续优化各自策略，实现集体行为的涌现进化。
