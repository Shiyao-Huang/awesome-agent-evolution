## 概述
AlphaFold2生态系统是围绕DeepMind蛋白质结构预测技术构建的开源工具集，包括AlphaFold2推理管线、ColabFold轻量版、以及各种下游应用工具。它推动了结构生物学研究的范式转变。

## 核心特性
- AlphaFold2完整推理管线（含MSA生成和结构预测）
- 支持多聚体和蛋白质复合物预测
- 丰富的社区衍生工具（ColabFold、OpenFold等）
- 蛋白质结构数据库（AlphaFold DB）集成

## 技术栈
- Python
- JAX / Haiku
- HHblits / JackHMMER
- CUDA
- Docker

## 与 Self Evolve 的关联
AlphaFold生态系统展示了科学AI从单一突破到持续精炼进化的完整路径，社区反馈和迭代改进推动预测精度和应用范围不断扩展。
