# Google Research Football - Training with competitive Self-Play

[https://github.com/shehrum/grf-self-play#google-research-football---training-with-competitive-self-play](https://github.com/shehrum/grf-self-play#google-research-football---training-with-competitive-self-play)

This repository contains the implementation for competitive self-play with Google Research Football. Proximal Policy Optimisation is used to train the agent in a 11vs11 game using competitive self-play.

[https://github.com/shehrum/GRF-Self-Play/blob/master/images/game.png](https://github.com/shehrum/GRF-Self-Play/blob/master/images/game.png)

### Getting Started

[https://github.com/shehrum/grf-self-play#getting-started](https://github.com/shehrum/grf-self-play#getting-started)

Follow the installation instructions for [Google Research Football environment](https://github.com/google-research/football). After the environment is installed, clone this repository inside the the football environment folder.

### Dependencies

[https://github.com/shehrum/grf-self-play#dependencies](https://github.com/shehrum/grf-self-play#dependencies)

Use the `requirements.txt` to install the required dependencies.

```
pip install -r requirements.txt
```

### Instructions

[https://github.com/shehrum/grf-self-play#instructions](https://github.com/shehrum/grf-self-play#instructions)

1. You can run the training code for PPO using the following command in your terminal:

```
python train_ppo.py
```

This will start your model training, and save the results and the trained model in /ray_results. Modify the file for parameter tuning.

1. For evaluation, run the following command after adding the checkpoint path in the code file.

```
python eval.py
```
