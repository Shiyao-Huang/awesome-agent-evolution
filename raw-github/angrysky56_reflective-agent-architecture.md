## Quickstart Guide

[https://github.com/angrysky56/reflective-agent-architecture#quickstart-guide](https://github.com/angrysky56/reflective-agent-architecture#quickstart-guide)

Follow these steps to get the RAA MCP server running with your AI client (e.g., Claude Desktop).

### 1. Setup Environment & Dependencies

[https://github.com/angrysky56/reflective-agent-architecture#1-setup-environment--dependencies](https://github.com/angrysky56/reflective-agent-architecture#1-setup-environment--dependencies)

```
# Clone the repository
git clone https://github.com/angrysky56/reflective-agent-architecture.git
cd reflective-agent-architecture

# Install dependencies (using uv)
uv sync --extra server
```

### 2. Configure Services

[https://github.com/angrysky56/reflective-agent-architecture#2-configure-services](https://github.com/angrysky56/reflective-agent-architecture#2-configure-services)

**Ollama (LLM Backend)**

1. Install [Ollama](https://ollama.com/).
2. Start the service: `ollama serve`
3. Pull the required model: 

```
ollama pull qwen3:latest  # Or your preferred model defined in .env
```

**Neo4j (Graph Database)**

1. Install [Neo4j Desktop](https://neo4j.com/download/) or use Docker.
2. Start a database instance.
3. Note your password (default user is usually `neo4j`).

**Environment Variables**

1. Copy the example config: 

```
cp .env.example .env
```

## Multiple local and cloud servers can be set including major providers, LM Studio, and Open Router, see .env for details.

[https://github.com/angrysky56/reflective-agent-architecture#multiple-local-and-cloud-servers-can-be-set-including-major-providers-lm-studio-and-open-router-see-env-for-details](https://github.com/angrysky56/reflective-agent-architecture#multiple-local-and-cloud-servers-can-be-set-including-major-providers-lm-studio-and-open-router-see-env-for-details)

1. Edit `.env` and set your Neo4j password: 

```
NEO4J_PASSWORD=your_password
# Optional: Change LLM_MODEL or EMBEDDING_MODEL if desired
```

### 3. Configure MCP Client or the built in Dashboard UI

[https://github.com/angrysky56/reflective-agent-architecture#3-configure-mcp-client-or-the-built-in-dashboard-ui](https://github.com/angrysky56/reflective-agent-architecture#3-configure-mcp-client-or-the-built-in-dashboard-ui)

[https://github.com/angrysky56/reflective-agent-architecture/blob/main/image.png](https://github.com/angrysky56/reflective-agent-architecture/blob/main/image.png)

Add the RAA server to your client configuration (e.g., `claude_desktop_config.json`).

**Config Path:**

- Mac/Linux: `~/.config/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude
