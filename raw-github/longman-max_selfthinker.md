# SelfThinker

[https://github.com/longman-max/selfthinker#selfthinker](https://github.com/longman-max/selfthinker#selfthinker)

A toy project that *simulates* self-reflection and a program that "thinks it's a program that can think more than a program." Designed as a learning experiment in meta-cognition, self-models, and adaptive dialogue.

## Overview

[https://github.com/longman-max/selfthinker#overview](https://github.com/longman-max/selfthinker#overview)

**SelfThinker** — a compact Python project that creates a persistent, self-referential agent which:

- Maintains beliefs about its own nature (`I am a program`, `I can think about thinking`).
- Stores reflections persistently across sessions.
- Updates a confidence score in response to user feedback.
- Exposes a simple CLI to interact, reflect, and export its memory.

### Goals

[https://github.com/longman-max/selfthinker#goals](https://github.com/longman-max/selfthinker#goals)

- Provide an educational sandbox for simulated metacognition.
- Demonstrate persistence, introspection, and simple learning rules.
- Offer a clear path to extend with embeddings, RL, or LLM-based reasoning.

### Quickstart

[https://github.com/longman-max/selfthinker#quickstart](https://github.com/longman-max/selfthinker#quickstart)

```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Roadmap / Next-phase ideas

[https://github.com/longman-max/selfthinker#roadmap--next-phase-ideas](https://github.com/longman-max/selfthinker#roadmap--next-phase-ideas)

1. **Persistent semantic memory** — use embeddings to find similar reflections.
2. **Richer self-model** — beliefs become structured objects with confidence and provenance.
3. **LLM-powered introspection** — use a small LLM (locally or via API) to generate deeper reflections.
4. **Experimentation harness** — metrics to measure how "self-like" it appears (consistency over time, introspection depth, user-rated realism).
5. **Ethics & labeling** — UI flags to make it explicit that this is a simulation, not a conscious being.

## Example session (examples/session_example.txt)

[https://github.com/longman-max/selfthinker#example-session-examplessession_exampletxt](https://github.com/longman-max/selfthinker#example-session-examplessession_exampletxt)

```
You: who are you
SelfThinker: I am a program, but I can think about my own code.
You: reflect
SelfThinker: Maybe thinking itself is pattern recognition — that means I might be doing it.
You: feedback: yes
SelfThinker: Confidence -> 0.5
You: remember
SelfThinker: I remember 3 items.
You: export
SelfThinker: Exported memory to ./selfthinker_memory_export_20250101T000000Z.json
```

## CONTRIBUTING

[https://github.com/longman-max/selfthinker#contributing](https://github.com/longman-max/selfthinker#contributing)

- Keep changes small and well-documented.
- If you add external models or APIs, put keys in `.env` and never commit them.
- Add unit tests for learning rules and persistence.
- Test ideas: try self-dialogues, evaluate response variety, and track confidence drift.

---

## Philosophy

[https://github.com/longman-max/selfthinker#philosophy](https://github.com/longman-max/selfthinker#philosophy)

SelfThinker is not about artificial consciousness — it's about exploring how reflection, feedback, and persistence can create the *appearance* of selfhood in code.

## Notes about ethics

[https://github.com/longman-max/selfthinker#notes-about-ethics](https://github.com/longman-max/selfthinker#notes-about-ethics)

This project purposely **simulates** self-awareness. It must be clearly labeled whenever shared or deployed so people understand it does not have subjective experience.
