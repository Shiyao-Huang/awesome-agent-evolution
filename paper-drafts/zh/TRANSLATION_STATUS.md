## Blocker

Claude translation was started with per-file agents, but several remaining files failed because the Claude side hit rate limits and upstream provider errors:

- `429`: concurrency limit / account rate limit
- `502`: upstream request forwarding failure
- `503`: no available provider channel

Because of those failures, this directory is not yet a complete publishable bilingual version and should not replace `site/public/reports/self-evolve-survey-zh.pdf`.

`paper-drafts/zh/main.tex` is guarded so missing chapters render as explicit "translation pending" placeholders instead of failing. A one-pass XeLaTeX check succeeded and produced a 76-page partial draft before generated byproducts were removed from the worktree.
