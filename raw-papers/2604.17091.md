# GenericAgent: A Token-Efficient Self-Evolving LLM Agent via Contextual Information Density Maximization (V1.0)

**Authors**: Jiaqing Liang, Jinyi Han, Weijia Li, Xinyi Wang, Zhoujia Zhang, Zishang Jiang, Ying Liao, Tingyun Li, Ying Huang, Hao Shen, Hanyu Wu, Fang Guo, Keyi Wang, Zhonghua Hong, Zhiyu Lu, Lipeng Ma, Sihang Jiang, Yanghua Xiao

**Submitted**: 2026-04-18 (v1)

**Code**: https://github.com/lsdefine/GenericAgent

## Abstract

Long-horizon large language model (LLM) agents are fundamentally limited by context. As interactions become longer, tool descriptions, retrieved memories, and raw environmental feedback accumulate and push out the information needed for decision-making. At the same time, useful experience gained from tasks is often lost across episodes. We argue that long-horizon performance is determined not by context length, but by how much decision-relevant information is maintained within a finite context budget. We present GenericAgent (GA), a general-purpose, self-evolving LLM agent system built around a single principle: context information density maximization. GA implements this through four closely connected components: a minimal atomic tool set that keeps the interface simple, a hierarchical on-demand memory that only shows a small high-level view by default, a self-evolution mechanism that turns verified past trajectories into reusable SOPs and executable code, and a context truncation and compression layer that maintains information density during long executions. Across task completion, tool use efficiency, memory effectiveness, self-evolution, and web browsing, GA consistently outperforms leading agent systems while using significantly fewer tokens and interactions, and it continues to evolve over time.

## Key Contributions

1. **Context Information Density Maximization Principle**: Argues and demonstrates that long-horizon agent performance depends on decision-relevant information density within a finite context budget, not raw context length
2. **Four-Component Self-Evolving Architecture**: Implements self-evolution through a minimal atomic tool set, hierarchical on-demand memory, trajectory-to-SOP conversion, and context truncation/compression
3. **Token-Efficient Self-Evolution**: Consistently outperforms leading agent systems across task completion, tool use, memory, self-evolution, and web browsing while using significantly fewer tokens and interactions

## Relevance to Agent Evolution

GenericAgent directly addresses the context window management challenge that limits all self-evolving agents. Its SOP-based self-evolution mechanism (converting verified trajectories into reusable procedures and executable code) is a practical approach to experience accumulation that bridges Voyager-style skill libraries with production-grade systems. The token efficiency focus directly tackles the resource cost barrier of autonomous self-improvement.
