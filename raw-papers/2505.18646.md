# SEW: Self-Evolving Agentic Workflows for Automated Code Generation

- **arXiv ID**: 2505.18646

- **Authors**: Siwei Liu, Jinyuan Fang, Han Zhou, Yingxu Wang, Zaiqiao Meng

## Abstract

Novel self-evolving framework that automatically generates and optimises multi-agent workflows. SEW can automatically design agentic workflows and optimise them through self-evolution, bringing up to 33% improvement on LiveCodeBench compared to using the backbone LLM only.
