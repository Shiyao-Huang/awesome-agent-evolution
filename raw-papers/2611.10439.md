# Who Remembers What? Multi-Granularity Memory Extraction for Multi-User, Multi-Agent Interaction

**Authors**: Yunzhe Wang, Mesut Erhan Unal, Sheng Zhang, Shabnam Ghadar, Peng Tang

**Submitted**: 2026-11-07

**Venue**: arXiv preprint (2026)

**Code**: none (arXiv only)

## Abstract

Self-evolving agents improve their skills, memory, and harness code from experience without retraining the base LLM, and group-evolving agents extend this by sharing lessons across agents. The paper argues that sharing across many users and heterogeneous agents also requires deciding who can benefit from each lesson and what information must stay private. It introduces MixUA, a memory system that distills independent user-agent trajectories into lessons and assigns each lesson to a user-agent pair, user, agent, or global scope according to whom it benefits and what it may disclose. For evaluation it introduces CrossLearnBench, a mixed-user-agent benchmark that pairs established agent tasks with user preferences and privacy probes that check whether private facts leak into memory readable by other users. With five users and seven agents, MixUA improves pass rates over both no memory and a single global memory, including on tasks previously attempted only by other users on other agents, while retaining most stated preferences and keeping privacy-probe leakage near zero.

## Key Contributions

1. **MixUA scoped lesson memory**: Distills trajectories from many independent users and heterogeneous agents into lessons and assigns each lesson a sharing scope (user-agent pair, user, agent, or global) based on who benefits and what it may disclose.
2. **CrossLearnBench**: A mixed-user-agent benchmark that pairs agent tasks with user preferences and privacy probes, measuring cross-user and cross-agent transfer, preference retention, and private-fact leakage together.
3. **Evaluation at 5 users x 7 agents**: Up to +16 pass-rate points over no memory and +5 over a single global memory, up to 90% preference retention, and at most 0.02% of privacy probes finding a planted private fact in a forbidden scope.

## Relevance to Agent Evolution

MixUA is an experience-driven, group-level evolution loop: the mutable object is a shared lesson memory, the feedback signal is the outcome of trajectories collected across many users and agents, and the update step distills and scopes lessons so they can be reused by other users and agents. It extends single-agent experience learning and group-evolving experience sharing with an explicit privacy-aware scoping decision, which matters once one memory serves a population of users and agents.
