# Do Self-Evolving Agents Forget? Capability Degradation and Preservation in Lifelong LLM Agent Adaptation

**Authors**: Ye Yu, Xiaopeng Yuan, Haibo Jin, Heming Liu, Yaoning Yu, Haohan Wang

**Submitted**: 2026-05-10 (v1)

## Abstract

Recent advances in LLM agents enable systems that autonomously refine workflows, accumulate reusable skills, self-train their underlying models, and maintain persistent memory. However, we show that such self-evolution is often non-monotonic: adapting to new task distributions can progressively degrade previously acquired capabilities across all major evolution channels. We identify this phenomenon as capability erosion under self-evolution and show that it consistently emerges across workflow, skill, model, and memory evolution. To mitigate this issue, we propose Capability-Preserving Evolution (CPE), a general stabilization principle that constrains destructive capability drift during continual adaptation. Across all four evolution dimensions, CPE consistently improves retained capability stability while preserving adaptation performance. For example, in workflow evolution, CPE improves retained simple-task performance from 41.8% to 52.8% under GPT-5.1 optimization while simultaneously achieving stronger complex-task adaptation. Our findings suggest that stable long-horizon self-evolving agents require not only acquiring new capabilities, but also explicitly preserving previously learned ones during continual adaptation.

## Key Contributions

1. **Capability Erosion Phenomenon**: First systematic study showing self-evolution is non-monotonic — new learning degrades old capabilities
2. **Four-Channel Analysis**: Demonstrates erosion across workflow, skill, model, and memory evolution
3. **Capability-Preserving Evolution (CPE)**: General stabilization principle constraining destructive drift
4. **GPT-5.1 Validation**: Tested against latest frontier model (41.8% → 52.8% on retained tasks)
5. **Lifelong Learning Bridge**: Connects agent self-evolution with catastrophic forgetting literature

## Relevance to Agent Evolution

Critical paper that bridges self-evolving agents with lifelong learning / catastrophic forgetting research. The "capability erosion" finding validates the Mom Test complaint that "every session the agent re-learns from scratch for 4 minutes" — not because learning fails, but because adaptation destroys prior capabilities. CPE's four-channel analysis (workflow/skill/model/memory) directly maps to our survey's taxonomy. The GPT-5.1 validation makes this one of the most up-to-date evaluations in the field. Essential for the survey's safety/stability discussion.
