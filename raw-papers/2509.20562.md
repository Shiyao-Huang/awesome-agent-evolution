# SAMULE: Self-Learning Agents Enhanced by Multi-Level Reflection

- **arXiv ID**: 2509.20562
- **URL**: https://arxiv.org/abs/2509.20562
- **PDF**: https://arxiv.org/pdf/2509.20562
- **Authors**: Yubin Ge, Salvatore Romeo, Jason Cai, Monica Sunkara, Yi Zhang
- **Year**: 2025 (EMNLP 2025)

## Abstract

Framework for self-learning agents powered by a retrospective language model trained based on Multi-Level Reflection Synthesis. Synthesizes high-quality reflections across three complementary levels: Single-Trajectory Learning (micro-level), Intra-Task Learning (meso-level), and Inter-Task Learning (macro-level). Extends to interactive settings through foresight-based reflection mechanism.
