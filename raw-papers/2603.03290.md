## Abstract

Structured memory system for LLM agents that addresses disconnected evidence and state updates via a decoupled two-phase pipeline. Uses entropy-aware gating to filter noise, conflict-aware coarsening to merge duplicates, and algorithmic bridge discovery for multi-hop reasoning. Improves Multi-Hop F1 by 15.2% and reduces runtime by 77.8%.
