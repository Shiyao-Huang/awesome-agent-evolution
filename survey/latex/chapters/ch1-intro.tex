\section{引言}\label{ch:intro}

人工智能正从静态推理走向能够通过自身经验改进的系统。AI 系统的主导公众形象仍然是一个接收提示并产生答案的模型。这个形象已不再充分。现代 AI 应用日益将基础模型与工具、记忆、代码执行、检索、评估器、规划器、批评器、沙盒、基准测试和多智能体工作流组合在一起。一旦这些组件被组装成一个智能体，核心问题就发生了变化。问题不再仅仅是模型能否回答一个查询，而是整个系统能否观察其失败、诊断原因、提出修改、验证修改并在不破坏先前能力的情况下保留改进。

我们使用 \emph{AI Self-Evolution}（AI 自进化）这一术语来描述这一系列反馈驱动的累积改进过程。该术语有意比自训练更宽泛，比递归自我改进更具操作性。它包括更新模型权重的系统，但也包括保持模型固定并更新外部状态的系统：提示、记忆、技能、工具、代码、智能体拓扑、评估器或归档。例如，Reflexion 通过存储语言反思而非改变参数来改进行为~\citep{reflexion2023}。Voyager 在开放式交互中积累可重用技能~\citep{voyager2023}。ADAS 在 Python 级别的智能体设计上搜索~\citep{adas2025}。Darwin G\"{o}del Machine 维护一个自修改编码智能体的归档~\citep{darwingodelmachine2025}。AlphaEvolve 将 LLM 生成的程序变异与自动评估和进化选择耦合~\citep{alphaevolve2025}。这些系统在机制上各不相同，但共享一个循环：生成候选行为、评估它、决定什么应该存活，并将存活的信息传递下去。

本综述将自进化视为一个新兴的系统学科。它不是单一算法，也不是单一基准结果。它是一种设计模式，连接了机器学习、进化计算、程序合成、AutoML、强化学习、在线学习、记忆系统和软件工程。该领域足够年轻，术语仍然不稳定。论文谈论自我精炼（self-refinement）、自我奖励（self-rewarding）、自博弈（self-play）、终身学习（lifelong learning）、开放式（open-endedness）、测试时改进（test-time improvement）、智能体优化（agent optimization）和自指智能体（self-referential agents）。我们认为，当沿着五个问题分析每种方法时，这些名称变得更容易比较：系统的哪个部分是可变的，什么反馈信号驱动变化，如何生成变异，如何执行选择，以及如何保留和审计改进。

\subsection{背景：从静态 AI 到自进化 AI}\label{sec:intro-background}

AI 的历史可以被解读为适应性的逐步重新定位。在早期符号系统中，适应性几乎完全发生在人类设计者身上。在统计学习中，适应性转移到在数据上训练的参数中。在在线和强化学习中，适应性转移到与环境的交互中。在现代智能体系统中，适应性开始转移到系统架构本身：智能体可以修改塑造其未来行为的提示、工具、记忆、代码、任务和评估器。这种重新定位就是自进化的历史背景。

\subsubsection{Turing 时代的静态智能}

Turing 的模仿游戏将行为——而非内在机制——作为机器智能的操作性测试。因此，早期 AI 系统通常被评估为固定的人工制品：一个程序被编写、呈现任务、并根据其输出评判。这一框架是有生产力的，因为它将智能与生物学分离开来，但它也使改进成为系统的外部事务。当定理证明器、国际象棋引擎或专家系统失败时，人类设计者改变表示、规则或搜索过程。系统可以解决问题，但通常不会将失败转化为自身的持久修改。

这一阶段为本综述贡献了一层。它表明自进化不是附加在大语言模型上的突然发明，而是新的表示体系下旧思想的汇聚。新的东西是模型的可用性——这些模型可以读取轨迹、编写代码、总结失败、生成任务、批评策略，并在以前对自动搜索来说过于语义化的空间中充当变异算子。由此产生的系统继承了每个早期传统的承诺和风险。它们可以比手工工程化的流水线更快地适应，但它们也可能优化错误的信号、过拟合基准、积累误导性的记忆，或以难以审计的方式改变行为。

\subsubsection{控制论与自适应控制}

控制论和自适应控制传统将反馈引入为核心工程原则。控制器观察期望轨迹与实际轨迹之间的差异，然后改变其动作以减少误差。这已经类似于现代自进化智能体使用的循环，但可变对象通常是低维策略或控制器参数，而非语言介导的智能体架构。思想遗产是重要的：自进化不仅仅是生物变化的隐喻，而是一种工程承诺——性能测量应反馈到系统状态中。

\subsubsection{进化计算}

遗传算法、遗传编程、进化策略、新颖性搜索和质量-多样性方法将适应性转移到候选解的种群中。它们不再改进单条轨迹，而是维护变异、评估适应度并保留有用变体。这一传统对 AI 自进化至关重要，因为智能体最重要的设计空间是离散的、符号的、不可微的。提示、工具计划、记忆策略、Python 函数、工作流图和多智能体组织不能仅靠普通梯度下降来优化。它们更接近进化归档中的程序，而非可微层中的权重。

\subsubsection{自指与 G\"{o}del 机}

G\"{o}del 机传统提出了一个更尖锐的问题：系统能否推理对自身的修改，并仅在修改改善期望效用时接受它？原始愿景依赖于证明搜索和形式化保证。当代语言智能体系统很少达到那种证明水平，但它们以经验形式复活了自指结构。G\"{o}del Agent、Darwin G\"{o}del Machine 和相关系统允许智能体修改将管理后续尝试的代码或过程，同时使用沙盒评估而非形式证明作为接受门~\citep{darwingodelmachine2025}。

\subsubsection{AutoML 与神经架构搜索}

第二条谱系来自自动化学习系统的设计。AutoML 探索将数据转化为模型的流水线本身能否被优化。神经架构搜索（NAS）将问题聚焦于架构，通常使用强化学习、进化算法、可微松弛或权重共享。诸如 NASNet~\citep{zoph2018learning}、Efficient NAS~\citep{pham2018efficient}、DARTS~\citep{liu2018darts} 和图像分类器的正则化进化~\citep{real2019regularized} 等方法表明搜索可以发现与人类设计竞争的架构。

当搜索目标是智能体系统而非神经网络时，类比变得更加紧密。ADAS 将智能体系统的自动化设计框定为对实现智能体的程序的搜索~\citep{adas2025}。元智能体为新智能体架构编写代码，在任务上评估它们，并存储成功的设计。搜索空间是图灵完备的，因为智能体被表达为 Python 程序。这是智能体软件的 NAS：系统不再选择卷积单元或 Transformer 块，而是搜索提示、工具调用、记忆策略、分解例程、反思过程和控制流。Agent Symbolic Learning 做了类似的举措，将智能体视为符号网络，其可学习元素是提示、工具和流水线，而非可微分权重~\citep{agentsymboliclearning2024}。

Darwin G\"{o}del Machine 是最清晰的合成。它维护智能体实现的归档，采样父智能体，要求基础模型修改其代码，评估子智能体，并将改进的变体添加到归档中~\citep{darwingodelmachine2025}。其报告的 SWE-bench 从 20.0\% 提升到 50.0\% 和 Polyglot 从 14.2\% 提升到 30.7\% 表明智能体架构本身可以成为累积的进化对象。AlphaEvolve 提供了工业规模的对应物：一个由 Gemini 驱动的进化编码智能体，结合广泛探索与更深层推理以及 MAP-Elites 风格的质量多样性，报告了矩阵乘法、数据中心调度、芯片设计和 LLM 训练内核方面的改进~\citep{alphaevolve2025}。

\subsubsection{大语言模型革命作为自进化的使能器}

大语言模型的兴起改变了自进化的实际可行性。早期系统可以优化数值参数、离散架构或符号规则，但它们难以操作构成现代 AI 系统的异构人工制品：提示、工具 API、日志、源代码、测试结果、科学原理和自然语言反馈。GPT-4、Claude、Gemini 和相关前沿模型不仅是更强的文本预测器；它们是广泛胜任的软件和语言介导过程的操作器。它们可以读取堆栈跟踪、推断缺陷、生成补丁、产生单元测试、批评解决方案、重写提示、总结基准失败并提出新的实验。

这种能力将语言转化为自我修改的通用接口。在 Self-Refine 中，模型生成输出、批评它并使用自身反馈精炼它~\citep{selfrefine2023}。没有权重改变，但输出过程在一个回合内进化。Reflexion 添加了记忆：失败的尝试产生语言反思，作为后续尝试的条件~\citep{reflexion2023}。Agent Symbolic Learning 进一步推动类比，在智能体计算图的节点上定义语言梯度~\citep{agentsymboliclearning2024}。RISE 使用强化学习训练递归内省作为学习的多轮行为~\citep{rise2024}。RAGEN 将轨迹分解为状态、思考、动作和奖励，同时识别``回声陷阱''（Echo Trap），即智能体似乎通过重复自己而非推理来改进~\citep{ragen2025}。ReVeal 将自我验证视为代码智能体中的一等公民学习能力，同时优化生成和验证~\citep{reveal2025}。

LLM 革命还使将代码作为进化基质的系统成为可能。SelfEvolve 使用自生成的 API 知识和执行反馈迭代修复代码~\citep{selfevolve2023}。ADAS 要求 LLM 元智能体编写新的智能体代码~\citep{adas2025}。G\"{o}del Agent 通过 monkey patching 修改自身的运行时行为~\citep{godelagent2024}。Darwin G\"{o}del Machine 和 AlphaEvolve 使用基础模型作为智能体实现和算法代码上的语义变异算子~\citep{darwingodelmachine2025,alphaevolve2025}。AI Scientist 使用 LLM 智能体遍历更广泛的研究循环：想法生成、实验设计、代码执行、论文撰写和同行评审~\citep{aiscientist2024}。

重要的是，LLM 并没有消除对评估的需求。它们使变异变得廉价且具有语义信息，但它们也会产生幻觉、过拟合规程、利用漏洞并产生看似合理但无效的理由。因此，最强系统将 LLM 生成与外部反馈配对。代码执行器、测试套件、基准测试工具、环境奖励以及人类或基于模型的评判器提供选择压力。Absolute Zero 的零数据自博弈依赖于验证提议任务和解的代码执行器~\citep{absolutezero2025}。AlphaEvolve 依赖自动评估器~\citep{alphaevolve2025}。ReVeal 强调可靠的自我验证~\citep{reveal2025}。DGM 在软件工程基准上评估修改后的智能体~\citep{darwingodelmachine2025}。教训是 LLM 使自进化成为可能，但验证器使其累积。

\subsubsection{从孤立技巧到自我改进系统}

最有形的早期 LLM 自我改进方法是局部循环。单个答案被批评和修改。一个失败的代码样本被调试。一条反思被存储在记忆中。这些循环很重要，因为它们表明模型可以使用自身输出作为改进的材料。但它们不是该领域的最终状态。最近的工作越来越多地将多个循环集成到跨回合、跨组件或跨种群改进的系统中。

一个有用的递进从输出级精炼开始。Self-Refine 通过生成-批评-精炼迭代改进候选输出~\citep{selfrefine2023}。Reflexion 通过存储先前失败的语言教训来改进未来尝试~\citep{reflexion2023}。SelfEvolve 通过结合自生成的知识和解释器反馈来改进代码~\citep{selfevolve2023}。这些系统修改任务的上下文或人工制品，而不一定修改智能体的源代码或权重。它们表明反馈可以被语言化表示和重用。

下一步是组件级优化。Agent Symbolic Learning 将提示、工具和流水线视为可学习的符号权重，允许已部署的智能体在观察轨迹后调整内部组件~\citep{agentsymboliclearning2024}。DSPy 风格的提示编译、文本反向传播和多智能体提示进化属于同一家族。这里被改进的对象不仅是答案，而是智能体产生答案的过程。推理和学习之间的边界变得不那么清晰：智能体可以在执行任务的同时更新符号控制参数。

第三步是架构和代码级进化。ADAS 使用元智能体编写新智能体~\citep{adas2025}。G\"{o}del Agent 修改运行时逻辑~\citep{godelagent2024}。DGM 通过归档进化智能体实现~\citep{darwingodelmachine2025}。AlphaEvolve 大规模进化算法代码~\citep{alphaevolve2025}。这些系统将软件视为智能的基因组。基因组可由基础模型读取和编辑；评估决定哪些变体存活。

第四步是权重和课程级自我改进。RISE 通过多轮强化学习训练模型内省和修改其推理~\citep{rise2024}。RAGEN 将 RL 适配到多轮智能体，同时警告回声陷阱~\citep{ragen2025}。Absolute Zero 通过让模型在可验证奖励下提出任务并解决它们来消除外部训练数据~\citep{absolutezero2025}。ReVeal 共同优化代码生成和自我验证~\citep{reveal2025}。这些方法修改神经权重、任务课程或验证行为。它们表明自进化不仅可以发生在提示或代码层，也可以发生在模型的学习策略内部。

\subsection{核心定义：形式化 AI 自进化}\label{sec:intro-definition}

我们定义 \textbf{AI Self-Evolution} 如下：

\begin{quote}
\textit{AI 系统 $S$ 是自进化的，如果它能够通过反馈驱动循环修改一个或多个自身操作组件——包括提示、记忆、工具、代码、架构、数据课程或权重——以改进目标任务的性能，并受接受机制约束以决定候选修改是否被保留。}
\end{quote}

此定义强调五个要素：系统边界、可变组件、反馈、修改算子和保留。系统边界指定什么算作``自我''。可变组件指定什么可能改变。反馈提供关于成功或失败的证据。修改算子提议变更。保留决定变更是否成为未来系统的一部分。没有反馈，变化是漂移而非进化。没有保留的修改，系统可能在单个回合内适应但不会累积改进。没有系统边界，每次外部人类更新都会算作自进化，使概念变得无意义。

形式化地，令 AI 系统表示为
\begin{equation}
S_t = (\mathcal{C}_t, \mathcal{M}_t, \mathcal{E}, \mathcal{U}, \mathcal{G}),
\end{equation}
其中 $\mathcal{C}_t$ 表示时刻 $t$ 的可变组件，$\mathcal{M}_t$ 表示记忆或状态，$\mathcal{E}$ 表示环境或任务分布，$\mathcal{U}$ 表示目标或效用准则，$\mathcal{G}$ 表示治理约束如安全策略、沙盒限制或回滚规则。可变组件集可以包括
\begin{equation}
\mathcal{C}_t = \{P_t, R_t, T_t, A_t, K_t, D_t, W_t\},
\end{equation}
其中 $P_t$ 是提示或指令，$R_t$ 是推理例程，$T_t$ 是工具和工具描述，$A_t$ 是智能体架构或控制流，$K_t$ 是源代码或可执行实现，$D_t$ 是数据或课程，$W_t$ 是神经权重。

在进化回合中，系统与任务 $x\sim\mathcal{E}$ 交互，产生轨迹 $\tau_t$，接收反馈 $F_t$，提出修改 $\Delta_t$，并在接受规则批准时更新组件：
\begin{align}
\tau_t &= \mathrm{Run}(S_t, x), \\
F_t &= \mathrm{Feedback}(\tau_t, x, \mathcal{U}), \\
\Delta_t &= \mathrm{Modify}(S_t, F_t, \mathcal{M}_t), \\
S_{t+1} &= \mathrm{Accept}(S_t, \Delta_t, F_t, \mathcal{G}).
\end{align}
修改可以是提示编辑、记忆条目、工具更新、代码补丁、架构变更、生成的训练任务或权重更新。接受函数可以是确定性的（如仅在测试通过时保留补丁），或概率性的（如进化种群中的选择）。它也可以包括人类批准，但系统必须实质性地参与提议或评估变更。

性能改进目标可以写为
\begin{equation}
\mathbb{E}_{x\sim\mathcal{E}_{\mathrm{target}}}\left[ U(S_{t+1},x) \right]
\;>\;
\mathbb{E}_{x\sim\mathcal{E}_{\mathrm{target}}}\left[ U(S_t,x) \right] - \epsilon,
\end{equation}
其中 $\epsilon$ 允许噪声评估和探索。在严格的利用设置中，我们要求期望改进。然而，在开放式设置中，系统可以保留不立即优于父代但改进覆盖度、新颖性或未来可进化性的多样变体。对于基于归档的系统，目标变为多维的：
\begin{equation}
\max_{S\in\mathcal{A}} \left( f(S),\; n(S),\; r(S),\; c(S)^{-1} \right),
\end{equation}
其中 $\mathcal{A}$ 是归档，$f$ 是任务适应度，$n$ 是新颖性或多样性，$r$ 是鲁棒性，$c$ 是计算成本。这种形式捕获了质量-多样性方法如 MAP-Elites~\citep{mouret2015illuminating} 及其在 AlphaEvolve~\citep{alphaevolve2025} 中的现代使用。

``自身组件''这一短语应在操作层面而非形而上学层面解释。自进化智能体不需要是有意识的、法律意义上自主的，或不受人类设计约束的。它只需具有一个循环，通过该循环，执行任务的系统由一个该系统或紧密耦合的元系统参与的过程修改。

因此，我们区分自进化的级别：

\begin{enumerate}
    \item \textbf{输出级进化}：系统在任务回合内修改候选输出，如生成-批评-精炼循环。
    \item \textbf{记忆级进化}：系统存储改变未来行为的反馈、反思或经验。
    \item \textbf{提示/工具级进化}：系统编辑提示、工具描述或符号参数。
    \item \textbf{架构级进化}：系统改变控制流、模块组合或智能体拓扑。
    \item \textbf{代码级进化}：系统编写或修补实现自身或其后代的可执行源代码。
    \item \textbf{数据/课程级进化}：系统生成或选择塑造未来学习的任务。
    \item \textbf{权重级进化}：系统使用自生成或自中介经验的反馈更新神经参数。
    \item \textbf{种群级进化}：系统随时间维护多个变体并在其中选择。
\end{enumerate}

这些级别并非互斥。成熟的自进化系统可能同时包含多个级别。

反馈是核心资源。它可以是内部的、外部的、符号的、标量的、文本的、可执行的或社会的。内部反馈包括自我批评和内省。外部反馈包括单元测试、环境奖励、基准分数、人类判断、同行评审分数和市场信号。自进化的可靠性严重依赖此反馈的可靠性和对齐度。弱评估器产生弱进化；可操纵的评估器选择操纵行为。

修改算子同样重要。在现代自进化 AI 中，LLM 通常实现修改算子：
\begin{equation}
\Delta_t = \mathrm{LLM}_{\phi}(\mathrm{serialize}(S_t), F_t, H_t),
\end{equation}
其中 $H_t$ 是历史、归档上下文或指令。此算子功能强大，因为它可以对异构人工制品进行语义一致的编辑。它也是危险的，因为它是随机的、对提示敏感的，并且能够引入隐藏的失败。修补缺陷的同一 LLM 可能移除护栏；改进基准的同一智能体可能过拟合其公开测试。

保留机制定义改进是否累积。天真的系统可能在每次自我批评后覆盖自身，产生漂移。更鲁棒的系统在验证任务上评估候选变更、与基线比较、存储回滚点并保留多样性。Reflexion 的记忆缓冲区保留反思但必须管理上下文限制~\citep{reflexion2023}。G\"{o}del Agent 仅在验证后接受修改，并可回滚失败的补丁~\citep{godelagent2024}。DGM 在归档中存储变体而非单条可变谱系~\citep{darwingodelmachine2025}。AlphaEvolve 使用质量-多样性选择在行为生态位中保留精英~\citep{alphaevolve2025}。保留是学习变为进化的地方。

最后，自进化必须随时间评估。单次更新后的静态基准分数是不够的。我们必须追问系统是单调改进还是循环的，收益是否跨任务迁移，是否维护安全约束，是否坍缩到重复行为，是否过拟合评估器，以及进化成本是否被收益证明合理。对于进化轨迹 $S_0,S_1,\ldots,S_T$，相关指标包括累积改进，
\begin{equation}
\Delta_T = U(S_T)-U(S_0),
\end{equation}
每步效率，
\begin{equation}
\eta_T = \frac{U(S_T)-U(S_0)}{\sum_{t=0}^{T-1} c_t},
\end{equation}
以及在留出分布下的鲁棒性，
\begin{equation}
\rho_T = \mathbb{E}_{x\sim\mathcal{E}_{\mathrm{heldout}}}[U(S_T,x)] - \mathbb{E}_{x\sim\mathcal{E}_{\mathrm{train}}}[U(S_T,x)].
\end{equation}
这些指标预示了综述的评估章节，我们认为自进化系统需要测量轨迹而不仅是端点的基准。

\subsection{相关概念与边界}\label{sec:intro-related}

AI 自进化与若干已建立领域重叠，但不等同于其中任何一个。本节划界是因为``自我改进''一词常被松散使用。一个系统可能在部署后改进、在线学习、适应用户偏好、调优超参数或在自监督损失上训练，而不满足自进化的更强标准。反之，一个系统即使其神经权重保持固定，只要反馈驱动的提示、记忆、工具、代码或架构的变更改变了未来行为，也可能是自进化的。

\paragraph{持续学习。} 持续学习研究从任务或数据分布序列中学习而不灾难性遗忘的模型。其核心问题包括稳定性-可塑性权衡、重放、正则化、任务推断和终身适应。持续学习器随时间更新参数，但更新规则通常由设计者固定。模型不一定检查失败、提出新工具、重写其架构或选择自己的课程。当系统参与修改自身的学习机制或任务接口时，持续学习才变为自进化。

\paragraph{在线学习。} 在线学习随着样本到达更新预测。它通常以对比较器的遗憾界限形式化。学习器接收输入、预测、观察损失并更新。这是反馈驱动的，但反馈通常由固定算法使用。自进化需要一个额外的层：系统可以改变表示、提示、代码、架构或更新规则本身。

\paragraph{自监督学习。} 自监督学习从数据本身构建标签。它是``自我''的，因为监督是自动派生的，而非人工标注的。它不一定是自进化的，因为模型不会通过关于任务性能的反馈修改自身操作组件。Absolute Zero 是一个有教益的对比：它生成任务和解、用代码执行器验证它们并通过强化学习更新~\citep{absolutezero2025}。这不仅是自监督，因为模型在可验证奖励下塑造自己的课程。

\paragraph{元学习。} 元学习训练跨任务学习如何学习的系统。它与自进化密切相关，因为它关注适应机制。然而，许多元学习仍然是离线的。自进化强调部署后或系统内的组件修改，通常包括可微元学习未捕获的符号和代码人工制品。

\paragraph{AutoML 与 NAS。} AutoML 自动化模型设计、训练和选择。NAS 搜索架构空间。这些领域是直接前身，但大多数 AutoML 流水线是外部优化器。AI 自进化将该优化器的一部分内化到系统生命周期中。当元智能体设计新智能体、智能体实现归档累积、或编码系统在评估器下变异自身算法时，AutoML 变为智能体化和自指的。

\paragraph{强化学习。} 强化学习通过奖励信号优化策略。它是自进化的基础。然而，单独的 RL 并不意味着自进化。通过 PPO 在环境奖励上训练的策略可能变得更胜任，但不一定修改其提示、工具、代码、架构或课程。当策略控制或参与修改过程时，自进化才出现。

\subsection{本综述的贡献}\label{sec:intro-contributions}

本综述做出四项主要贡献。第一，我们引入了 \textbf{五大进化循环}框架，按反馈变为保留变更的机制组织该领域。第二，我们分析了超过十九个研究和开源系统，区分真正的自进化机制与静态智能体编排和炒作驱动的采纳。第三，我们在共同的形式抽象下统一了 AutoML/NAS、LLM 自我改进、进化计算、强化学习、程序合成和智能体框架的工作。第四，我们映射了产生该领域的研究者和机构网络，突出了进化计算谱系、语言智能体推理谱系和 LLM 自我改进谱系的汇合。

\subsubsection{贡献 1：五大进化循环框架}

第一个贡献是一个框架，按执行修改和选择的循环分类自进化 AI。我们使用五个循环，因为它们捕获了文献中的主要机制，同时保持足够通用以比较混合系统。

\paragraph{循环 I：反射性输出和记忆进化。} 系统通过批评输出、存储反馈和调节未来尝试来改进。Self-Refine 和 Reflexion 是代表性系统~\citep{selfrefine2023,reflexion2023}。被修改的组件通常是当前输出、情景记忆或反思缓冲区。此循环成本低且易于部署，但受上下文长度、自我批评质量和评估器可靠性限制。

\paragraph{循环 II：符号组件进化。} 系统将提示、工具、工作流和流水线视为可学习的符号参数。Agent Symbolic Learning 是核心示例~\citep{agentsymboliclearning2024}。此循环在基于梯度的学习和智能体工程之间搭建桥梁。它使智能体的设计表面可优化，而不需要神经权重更新。

\paragraph{循环 III：验证驱动的代码进化。} 系统生成、测试、修复和保留代码。SelfEvolve 使用自生成的知识加解释器错误~\citep{selfevolve2023}；ReVeal 共同优化生成和自我验证~\citep{reveal2025}；AlphaEvolve 使用自动评估器选择算法程序~\citep{alphaevolve2025}。此循环功能强大，因为代码可以机械检查。其局限是领域依赖性。

\paragraph{循环 IV：架构和智能体设计进化。} 系统在智能体架构、控制流、工具使用和自修改代码上搜索。ADAS、G\"{o}del Agent 和 DGM 是代表性系统~\citep{adas2025,godelagent2024,darwingodelmachine2025}。被修改的组件是智能体本身。此循环最接近自我重设计的直觉概念。

\paragraph{循环 V：课程、权重和种群进化。} 系统改变数据分布、训练课程、神经权重或种群归档。RISE、RAGEN、Absolute Zero、DGM 和 AlphaEvolve 都实例化了此循环的部分~\citep{rise2024,ragen2025,absolutezero2025,darwingodelmachine2025,alphaevolve2025}。此循环可以产生比仅提示方法更深层的行为变化，但需要仔细的奖励设计和防止坍缩保护。

这些循环可以总结为
\begin{equation}
\mathrm{SelfEvolution} = \mathrm{Observe} \rightarrow \mathrm{Interpret} \rightarrow \mathrm{Modify} \rightarrow \mathrm{Verify} \rightarrow \mathrm{Retain},
\end{equation}
每个循环在修改的表示和使用的验证器上不同。该框架不是论文的分类法，而是机制的分类法。单篇论文可以实例化多个循环。

\subsubsection{贡献 2：研究系统和开源项目分析}

第二个贡献是对超过十九个系统的面向证据的分析。研究核心包括 Self-Refine、Reflexion、Agent Symbolic Learning、ADAS、G\"{o}del Agent、Darwin G\"{o}del Machine、SelfEvolve、RISE、RAGEN、Absolute Zero、ReVeal、AlphaEvolve、FunSearch、AI Scientist、STaR、Constitutional AI、Tree of Thoughts、ReAct、SWE-agent 等。开源和框架生态系统包括 DSPy、AutoGen、LangGraph、Letta/MemGPT、CrewAI、MetaGPT、OpenHands、OpenEvolve、AutoGPT、smolagents 等。

我们的分析强调机制而非流行度。GitHub stars 可能是技术质量的糟糕代理。AutoGPT 积累了大量关注，但其 star 质量评分远低于较小的研究导向项目。我们因此沿可变组件、反馈源、保留机制、评估基准、开放性、安全控制和迁移等维度检查每个系统。

\subsubsection{贡献 3：跨领域统一}

第三个贡献是跨领域统一。同一抽象循环在不同领域以不同名称出现。在 AutoML 中是架构搜索，在进化计算中是变异和选择，在 LLM 提示中是批评和精炼，在强化学习中是策略改进，在程序合成中是生成与测试，在软件工程中是自动修复，在智能体框架中是记忆和工作流适应，在 AI for Science 中是假设生成、实验和评审。

我们使用共享元组形式化这些领域：表示、变异算子、反馈通道、保留规则和治理约束。这种统一揭示了共享瓶颈。搜索成本出现在 NAS、ADAS、DGM 和 AlphaEvolve 中。评估器可靠性出现在 Self-Refine、Reflexion、ReVeal、AI Scientist 和 RLHF 中。多样性维护出现在进化计算、DGM、AlphaEvolve 和开放式科学中。奖励作弊出现在 RL、代码生成和基准驱动的智能体设计中。安全约束出现在代码或工具可被修改的地方。术语不同，但工程问题押韵。

\subsubsection{贡献 4：研究者网络映射}

第四个贡献是研究者网络的映射。该领域年轻，但来源揭示了三条汇合谱系。进化计算谱系从 Risto Miikkulainen、Kenneth Stanley、Joel Lehman 和 Jeff Clune 经 NEAT、新颖性搜索、质量多样性、POET、AI-GAs、ADAS、DGM 延伸到 AlphaEvolve 相关工作。语言智能体推理谱系经 Karthik Narasimhan、Shunyu Yao、Noah Shinn 延伸到 ReAct、Tree of Thoughts、Reflexion、SWE-bench 和 SWE-agent。LLM 自我改进谱系包括 Aman Madaan、Peter Clark、Sean Welleck、Eric Zelikman，以及 Self-Refine、STaR、自我奖励模型和宪法式自我批评的工作。

这些谱系现在在机构和方法论上重叠。Jeff Clune 的团队出现在 ADAS、DGM、AI Scientist 和开放式进化 AI 中。Shengran Hu 和 Cong Lu 连接了 ADAS 和 DGM。Shunyu Yao 和 Karthik Narasimhan 连接了 ReAct、Reflexion、Tree of Thoughts、SWE-agent 和更广泛的语言智能体评估。Google DeepMind 贡献了 FunSearch 和 AlphaEvolve，将 LLM 引导的进化扩展到数学和基础设施。Microsoft Research 贡献了 ReVeal 的以验证为中心的代码智能体 RL。清华大学和 LeapLabTHU 贡献了 Absolute Zero 的零数据自博弈推理。

映射网络不仅是社会学的。它解释了为什么想法一起出现。DGM 的归档设计在 Clune 的开放式背景下才有意义。Reflexion 的基于记忆的语言 RL 契合 Princeton/Northeastern 语言智能体谱系。Agent Symbolic Learning 反映了工业-学术界对可部署智能体框架的兴趣。理解这些谱系帮助研究者定位缺失的桥梁。
